# 멀리 뛰기

## 문제 설명

한 번에 `1칸` 또는 `2칸`을 이동할 수 있을 때, 총 `n칸`을 이동하는 방법의 수를 구합니다.  
방법의 수가 커질 수 있으므로 결과를 `1,000,000,007`로 나눈 나머지를 반환합니다.

## 풀이 방법

`i`번째 칸에 도착하는 마지막 이동은 다음 두 가지입니다.

- `i - 1`번째 칸에서 `1칸` 이동
- `i - 2`번째 칸에서 `2칸` 이동

따라서 `i`칸까지 이동하는 방법의 수는 아래 점화식으로 구할 수 있습니다.

```text
dp[i] = dp[i - 1] + dp[i - 2]
```

초기값은 다음과 같습니다.

```text
dp[1] = 1
dp[2] = 2
```

`3`부터 `n`까지 순서대로 방법의 수를 계산하고, 매 연산마다 `1,000,000,007`로 나눈 나머지를 저장합니다.

## 코드

```java
class Solution {
    public int solution(int n) {
        int answer = 0;
        long[] dp = new long[n + 1];

        if (n == 1) answer = 1;
        else if (n == 2) answer = 2;
        else {
            dp[1] = 1;
            dp[2] = 2;

            for (int i = 3; i < n + 1; i++) {
                dp[i] = (dp[i - 1] + dp[i - 2]) % 1000000007;
            }

            answer = (int) dp[n];
        }

        return answer;
    }
}
```

## 복잡도

- 시간 복잡도: `O(n)`
- 공간 복잡도: `O(n)`

## 핵심 포인트

현재 칸에 도착하는 방법은 바로 이전 칸과 두 칸 이전 위치에서 오는 경우의 합입니다. 따라서 피보나치 수열과 같은 형태의 동적 계획법으로 해결할 수 있습니다.
