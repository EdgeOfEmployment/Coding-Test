# 알고리즘 분류
구현? 해시맵?

# 문제 풀이
시작 시간이 빠른 일정부터 차곡차곡 쌓는다. 이때 빠른 순으로 정렬하기 위해 문자열 날짜를 분으로 환산한 정수로 변환해서 다시 저장하고, 람다함수를 이용한 정렬함수로 정렬한다.
이후 해시맵을 사용해 종료 시간을 갱신해나가며 필요한 룸 수를 계산한다. 종료 시간 +10 보다 추가하려는 일정의 시작 시간이 같거나 크면 그 룸에 추가할 수 있으므로 해시맵 특징을 이용해 종료 시간을 추가한 시간으로 갱신한다. 
그게 아니고 일정이 겹치면 룸을 추가해야 하므로 룸 번호를 증가시키고 일정을 추가한다.
