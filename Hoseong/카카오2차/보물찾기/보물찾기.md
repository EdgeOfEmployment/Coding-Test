# 🌟 [프로그래머스] 보물 발굴 풀이

> **핵심 아이디어 : 최악의 경우 발생하는 비용을 최소화하는 인터벌 DP + 최적 의사결정 트리**

---

## 문제 분석

굴착 로봇은 원하는 열 하나를 선택하여 끝까지 판다.

한 번 굴착할 때마다 해당 열의 깊이(`depth[i]`)만큼 비용이 발생하며,

굴착 결과는 다음 셋 중 하나이다.

- `0` : 현재 열에 보물이 있다.
- `-1` : 보물이 왼쪽에 있다.
- `1` : 보물이 오른쪽에 있다.

즉, 한 번의 굴착은 **비교 연산**과 동일하며,

굴착 비용이 모두 다르다는 점만 일반적인 이진 탐색과 다르다.

---

# 핵심 관찰

일반적인 이진 탐색은

항상 가운데를 선택한다.

하지만 이 문제는

```
비용 = depth[col]
```

이므로

가운데가 매우 깊다면 손해가 될 수도 있다.

예를 들어

```
depth

[1, 1000, 1]
```

이라면

가운데를 먼저 파면

```
1000
```

의 비용이 발생한다.

반면

```
1 → 2
```

순으로 탐색하면

```
1 + 1000 = 1001
```

```
3 → 2
```

순으로 탐색해도

```
1 + 1000 = 1001
```

즉 단순한 이진 탐색이 항상 최적은 아니다.

---

# 의사결정 트리

현재 탐색 가능한 구간을

```
[L, R]
```

이라고 하자.

첫 번째로

```
i
```

열을 굴착한다고 하면

가능한 결과는

```
보물 발견

또는

왼쪽

또는

오른쪽
```

이다.

왼쪽이라면

```
[L, i-1]
```

만 탐색하면 되고,

오른쪽이라면

```
[i+1, R]
```

만 탐색하면 된다.

따라서

```
i를 먼저 판 이후의 비용
=
현재 비용
+
남은 구간의 비용
```

이 된다.

---

# DP 정의

다음을 정의한다.

```
solve(L,R)
```

=

구간 `[L,R]`에서

보물을 반드시 찾기 위한 **최소 최악 비용**

이다.

---

# 기저 사례

탐색할 열이 하나뿐이라면

```
[L,L]
```

반드시 그 열을 파야 한다.

따라서

```cpp
solve(L,L)=depth[L]
```

이다.

---

# 상태 전이

현재

```
[L,R]
```

에서

처음으로

```
i
```

열을 판다고 하자.

이번 굴착 비용은

```
depth[i]
```

이다.

이후 가능한 경우는

```
왼쪽

또는

오른쪽
```

뿐이다.

최악의 경우를 고려해야 하므로

```
depth[i]
+
max(
    solve(L,i-1),
    solve(i+1,R)
)
```

이 된다.

이를 모든 i에 대해 계산한 뒤

가장 작은 값을 선택하면 된다.

즉,

```
solve(L,R)

=

min(
depth[i]
+
max(
solve(L,i-1),
solve(i+1,R)
))
```

이다.

---

# 최적 선택 저장

최소 비용을 만드는

```
i
```

를 함께 저장해 둔다.

```cpp
best_choice[L][R]
```

에는

구간 `[L,R]`에서

가장 먼저 굴착해야 하는 열이 저장된다.

이후 실제 탐색 과정에서는

DP를 다시 계산할 필요 없이

저장된 값을 그대로 따라가기만 하면 된다.

---

# 실제 탐색

초기 구간은

```
L = 1
R = w
```

이다.

반복하면서

```
target = best_choice[L][R]
```

를 선택한다.

굴착 결과가

```
0
```

이면

보물을 찾은 것이므로 종료한다.

```
-1
```

이면

왼쪽만 남으므로

```
R = target-1
```

으로 줄인다.

```
1
```

이면

오른쪽만 남으므로

```
L = target+1
```

으로 줄인다.

이 과정을 반복하면

DP가 만든 최적 의사결정 트리를 그대로 따라가게 된다.

---

# Adaptive 채점 대응

일부 채점에서는

굴착할 때마다 보물 위치가 바뀔 수 있다.

단,

이전 결과와 모순되지는 않는다.

즉,

항상 **현재 가능한 후보 구간 안**에만 존재한다.

우리 알고리즘은

항상

```
현재 남은 구간
```

만을 기준으로

다음 굴착 위치를 결정한다.

따라서 보물이 이동하더라도

현재까지 받은 응답과 모순되지 않는 한

반드시 찾을 수 있다.

---

# 시간 복잡도

DP 상태 수는

```
O(w²)
```

이다.

각 상태마다

모든 열을 후보로 검사하므로

```
O(w)
```

이 필요하다.

따라서 전체 시간 복잡도는

```
O(w³)
```

이다.

`w ≤ 200`이므로

약

```
200³ = 8,000,000
```

번의 연산으로 충분히 해결 가능하다.

공간 복잡도는

```
O(w²)
```

이다.

# 구현 코드

```cpp
#include <string>
#include <vector>
#include <algorithm>
#include <cstring>
#include <climits>

using namespace std;

extern int excavate(int);

// DP 메모이제이션
long long memo[205][205];

// 각 구간에서 가장 먼저 굴착해야 할 열
int best_choice[205][205];

long long solve(int L, int R, const vector<int>& depth) {
    if (L > R) return 0;

    if (L == R)
        return depth[L - 1];

    if (memo[L][R] != -1)
        return memo[L][R];

    long long min_cost = LLONG_MAX;
    int choice = L;

    for (int i = L; i <= R; i++) {
        long long left =
            (L <= i - 1)
            ? solve(L, i - 1, depth)
            : 0;

        long long right =
            (i + 1 <= R)
            ? solve(i + 1, R, depth)
            : 0;

        long long worst =
            depth[i - 1] + max(left, right);

        if (worst < min_cost) {
            min_cost = worst;
            choice = i;
        }
        else if (worst == min_cost) {
            // 동일 비용이면 더 얕은 열을 우선 선택
            if (depth[i - 1] < depth[choice - 1])
                choice = i;
        }
    }

    best_choice[L][R] = choice;
    return memo[L][R] = min_cost;
}

int solution(vector<int> depth, int money) {
    int w = depth.size();

    memset(memo, -1, sizeof(memo));
    memset(best_choice, 0, sizeof(best_choice));

    solve(1, w, depth);

    int L = 1;
    int R = w;

    while (L <= R) {
        int target;

        if (L == R)
            target = L;
        else
            target = best_choice[L][R];

        int result = excavate(target);

        if (result == 0)
            return target;

        if (result == -1)
            R = target - 1;
        else
            L = target + 1;
    }

    return L;
}
```
