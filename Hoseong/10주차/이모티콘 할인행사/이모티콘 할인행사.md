## 📌 1. 문제 개요 및 목표

카카오톡에서는 **이모티콘 플러스** 서비스 가입자를 늘리기 위해 이모티콘 할인 행사를 진행합니다.  
할인율은 각 이모티콘마다 **10%, 20%, 30%, 40%** 중 하나로 설정할 수 있습니다.

### 🎯 최우선 목표 (우선순위 순)
1. **이모티콘 플러스 서비스 가입자를 최대한 늘릴 것** (1순위)
2. **이모티콘 판매액을 최대한 늘릴 것** (2순위)

### 🛒 사용자 구매 규칙
- 각 사용자는 자신이 설정한 **기준 할인율(%) 이상**인 이모티콘을 모두 구매합니다.
- 각 사용자의 이모티콘 구매 총금액이 자신이 설정한 **기준 금액 이상**이 되면, **구매를 모두 취소하고 이모티콘 플러스 서비스에 가입**합니다.

---

## 💡 2. 문제 접근법 및 복잡도 분석

### 🔍 왜 완전 탐색(DFS)인가?
제한사항을 살펴보면 탐색 범위가 매우 작습니다.

- **이모티콘 개수 ($m$):** $1 \le m \le 7$
- **할인율 종류:** 4개 (`10%`, `20%`, `30%`, `40%`)
- **사용자 수 ($n$):** $1 \le n \le 100$

가능한 모든 할인율 조합의 수는 $4^m$ 가지입니다.
- 이모티콘이 최대 7개일 때 경우의 수: $4^7 = 16,384$가지
- 조합당 사용자 계산 수: $16,384 \times 100명 \times 7개 \approx 11,468,800$ 연산

컴퓨터 연산 속도(1초당 약 1억 번 연산) 기준으로 약 **0.01초 내외**에 모든 탐색을 완료할 수 있으므로, **DFS를 통한 완전 탐색(Brute Force)**이 가장 확실하고 직관적인 접근법입니다.

## 💻 3. 전체 구현 코드 (C++)

```cpp
#include <string>
#include <vector>
#include <functional>

using namespace std;

vector<int> solution(vector<vector<int>> users, vector<int> emoticons) {
    int m = emoticons.size();
    int n = users.size();
    
    // 가능한 할인율 옵션
    vector<int> discounts = {10, 20, 30, 40};
    vector<int> combo(m, 0); // 각 이모티콘의 할인율을 저장할 배열
    
    int bestSubscribers = 0; // 최대 가입자 수
    int bestSales = 0;       // 최대 매출액

    // DFS 람다 함수 정의
    function<void(int)> dfs = [&](int idx) {
        // [기저 조건] 모든 이모티콘의 할인율이 결정된 경우
        if (idx == m) {
            int subscribers = 0;
            int sales = 0;
            
            // 모든 사용자에 대해 계산
            for (int i = 0; i < n; i++) {
                int ratio = users[i][0]; // 사용자 기준 할인율
                int limit = users[i][1]; // 사용자 기준 금액
                int cost = 0;
                
                for (int j = 0; j < m; j++) {
                    if (combo[j] >= ratio) {
                        cost += emoticons[j] * (100 - combo[j]) / 100;
                    }
                }
                
                // 임계값 이상 구매시 가입 전환, 미만시 결제 진행
                if (cost >= limit) {
                    subscribers++;
                } else {
                    sales += cost;
                }
            }
            
            // 최적 결과 갱신 (1순위: 가입자 수, 2순위: 매출액)
            if (subscribers > bestSubscribers ||
               (subscribers == bestSubscribers && sales > bestSales)) {
                bestSubscribers = subscribers;
                bestSales = sales;
            }
            return;
        }
        
        // 4가지 할인율 중 하나를 선택하고 다음 이모티콘으로 재귀 호출
        for (int d : discounts) {
            combo[idx] = d;
            dfs(idx + 1);
        }
    };

    // DFS 탐색 시작 (0번 이모티콘부터)
    dfs(0);

    return {bestSubscribers, bestSales};
}
```

## 🔬 4. 핵심 로직 상세 설명 (Line-by-Line)

### ① 할인율 조합 생성 (DFS 재귀)
```cpp
for (int d : discounts) {
    combo[idx] = d;
    dfs(idx + 1);
}
```
- `discounts = {10, 20, 30, 40}` 배열을 돌며 현재 `idx`번째 이모티콘의 할인율을 결정합니다.
- `dfs(idx + 1)`을 호출하여 다음 이모티콘 할인율을 정하는 단계로 들어갑니다.

### ② 사용자별 구매 및 가입 여부 계산 (기저 조건)
```cpp
int ratio = users[i][0];
int limit = users[i][1];
int cost = 0;
for (int j = 0; j < m; j++) {
    if (combo[j] >= ratio) {
        cost += emoticons[j] * (100 - combo[j]) / 100;
    }
}
if (cost >= limit) subscribers++;
else sales += cost;
```
- `combo[j] >= ratio`: 사용자가 설정한 기준 할인율 이상 할인하는 이모티콘만 카트에 담아 계산합니다.
- `cost >= limit`: 결제 예정 금액이 `limit` 이상이면 이모티콘 구매를 **전면 취소**하고 **이모티콘 플러스 가입자(`subscribers++`)**로 전환합니다.
- 그렇지 않다면 가입하지 않고 결제 금액을 전체 매출(`sales`)에 합산합니다.

### ③ 최적 결과 갱신 (우선순위 적용)
```cpp
if (subscribers > bestSubscribers ||
   (subscribers == bestSubscribers && sales > bestSales)) {
    bestSubscribers = subscribers;
    bestSales = sales;
}
```
- **1순위 조건:** 현재 조합의 가입자 수(`subscribers`)가 기존 최대 가입자 수(`bestSubscribers`)보다 크면 무조건 갱신.
- **2순위 조건:** 가입자 수가 동일한 경우에는 매출액(`sales`)이 기존 최대 매출액(`bestSales`)보다 클 때만 갱신.
