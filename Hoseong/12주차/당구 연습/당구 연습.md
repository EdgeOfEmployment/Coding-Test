# [프로그래머스] 당구 연습 - C++ 풀이

## 1. 문제 설명
가로 `m`, 세로 `n`인 당구대에서 머쓱이가 `(startX, startY)`에 놓인 공을 쳐서, 벽에 **적어도 한 번** 맞힌 뒤 목표 공 `balls[i]`를 맞힐 때 공이 굴러가는 최소 거리의 **제곱**을 각 목표 공마다 구하는 문제입니다.

- 벽에 부딪힐 때 입사각과 반사각은 같습니다.
- 공의 크기는 무시하며, 좌표가 정확히 일치할 때만 맞은 것으로 봅니다.

---

## 2. 제한사항
- 3 ≤ `m`, `n` ≤ 1,000
- 0 < `startX` < `m`, 0 < `startY` < `n`
- 2 ≤ `balls`의 길이 ≤ 1,000
- 0 < `a` < `m`, 0 < `b` < `n`
- `(a, b) ≠ (startX, startY)`

---

## 3. 핵심 풀이 접근 방식 (기하 / 대칭 이동)

1. **대칭점으로 반사 경로를 직선화**
   - 벽에 반사되는 경로는 목표 공을 그 벽 기준으로 대칭 이동시킨 점까지의 직선 거리와 같습니다.
   - 4개의 벽에 대해 대칭점을 구합니다.
     - 왼쪽 벽: `(-a, b)`
     - 오른쪽 벽: `(2m-a, b)`
     - 아래쪽 벽: `(a, -b)`
     - 위쪽 벽: `(a, 2n-b)`

2. **경로 위에 목표 공이 있는 경우 제외**
   - 시작 공과 목표 공이 같은 축 위에 있고, 목표 공이 벽 방향 경로 위에 놓이면 벽에 닿기 전에 목표 공에 먼저 맞으므로 그 벽은 후보에서 제외합니다.
   - 예) 왼쪽 벽: `startY == b && a < startX`

3. **최솟값 선택**
   - 가능한 벽들의 `dx² + dy²` 중 최솟값을 정답으로 합니다. 제곱 값을 그대로 쓰므로 루트 연산이 필요 없습니다.

---

## 4. C++ 정답 코드

```cpp
#include <vector>
#include <algorithm>
#include <climits>

using namespace std;

vector<int> solution(int m, int n, int startX, int startY, vector<vector<int>> balls) {
    vector<int> answer;

    for (const auto& ball : balls) {
        int a = ball[0];
        int b = ball[1];
        int best = INT_MAX;

        // 왼쪽 벽: 대칭점 (-a, b)
        if (!(startY == b && a < startX)) {
            int dx = startX + a, dy = startY - b;
            best = min(best, dx * dx + dy * dy);
        }
        // 오른쪽 벽: 대칭점 (2m-a, b)
        if (!(startY == b && a > startX)) {
            int dx = startX - (2 * m - a), dy = startY - b;
            best = min(best, dx * dx + dy * dy);
        }
        // 아래쪽 벽: 대칭점 (a, -b)
        if (!(startX == a && b < startY)) {
            int dx = startX - a, dy = startY + b;
            best = min(best, dx * dx + dy * dy);
        }
        // 위쪽 벽: 대칭점 (a, 2n-b)
        if (!(startX == a && b > startY)) {
            int dx = startX - a, dy = startY - (2 * n - b);
            best = min(best, dx * dx + dy * dy);
        }

        answer.push_back(best);
    }
    return answer;
}
```

---

## 5. 복잡도 분석
- **시간 복잡도**: $O(B)$
  - $B$는 목표 공의 개수(최대 1,000)이며, 공마다 4개의 벽만 확인합니다.
- **공간 복잡도**: $O(B)$
  - 결과 배열만 추가로 사용합니다.
