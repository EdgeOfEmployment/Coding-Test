# [프로그래머스] 방금그곡 - C++ 풀이

## 1. 문제 설명
네오가 기억한 멜로디 `m`과 방송된 곡 정보 `musicinfos`(시작 시각, 끝난 시각, 제목, 악보)가 주어질 때, 기억한 멜로디가 실제 재생된 음 안에 포함된 곡의 제목을 찾는 문제입니다.

- 각 음은 1분에 1개씩 재생되며, 재생 시간이 악보보다 길면 처음부터 반복 재생, 짧으면 재생 시간만큼만 재생됩니다.
- 조건에 맞는 곡이 여러 개면 재생 시간이 가장 긴 곡, 재생 시간도 같으면 먼저 입력된 곡을 반환합니다.
- 조건에 맞는 곡이 없으면 `"(None)"`을 반환합니다.

---

## 2. 제한사항
- `m`은 음 1개 이상 1439개 이하
- `musicinfos`는 100개 이하, 각 원소는 `"시작,끝,제목,악보"` 형식 (`,`로 구분)
- 시각은 24시간 `HH:MM` 형식이며, 음악이 00:00를 넘겨 재생되는 일은 없습니다.
- 악보는 음 1개 이상 1439개 이하, 음은 `C, C#, D, D#, E, F, F#, G, G#, A, A#, B` 12개

---

## 3. 핵심 풀이 접근 방식 (문자열 처리 / 구현)

1. **`#` 음 치환 (`convert`)**
   - `C#`처럼 두 글자인 음을 `c`처럼 소문자 한 글자로 바꿉니다.
   - 그렇지 않으면 `ABC#` 안에서 `ABC`가 잘못 매칭되는 문제가 생깁니다.

2. **재생 시간 계산 (`toMinutes`)**
   - `HH:MM`을 분 단위로 변환해 `끝 - 시작`으로 재생 시간을 구합니다.

3. **실제 재생된 멜로디 생성**
   - `score[i % score.size()]`로 재생 시간만큼 악보를 반복해 이어 붙입니다.

4. **부분 문자열 검사 및 최댓값 갱신**
   - `played.find(target)`으로 기억한 멜로디 포함 여부를 확인합니다.
   - `playTime > maxTime`일 때만 갱신하므로, 재생 시간이 같으면 먼저 입력된 곡이 유지됩니다.

## 4. C++ 정답 코드

```cpp
#include <string>
#include <vector>
#include <sstream>

using namespace std;

// 시각(HH:MM)을 분 단위로 변환
int toMinutes(const string& t) {
    return stoi(t.substr(0, 2)) * 60 + stoi(t.substr(3, 2));
}

// '#'이 붙은 음을 소문자 한 글자로 치환
string convert(const string& s) {
    string res;
    for (size_t i = 0; i < s.size(); i++) {
        if (i + 1 < s.size() && s[i + 1] == '#') {
            res += (char)(s[i] + 32);
            i++;
        } else {
            res += s[i];
        }
    }
    return res;
}

string solution(string m, vector<string> musicinfos) {
    string answer = "(None)";
    int maxTime = -1;
    string target = convert(m);

    for (const string& info : musicinfos) {
        vector<string> tok;
        stringstream ss(info);
        string part;
        while (getline(ss, part, ',')) tok.push_back(part);

        int playTime = toMinutes(tok[1]) - toMinutes(tok[0]);
        string title = tok[2];
        string score = convert(tok[3]);

        string played;
        for (int i = 0; i < playTime; i++)
            played += score[i % score.size()];

        if (played.find(target) != string::npos && playTime > maxTime) {
            maxTime = playTime;
            answer = title;
        }
    }
    return answer;
}
```

## 5. 복잡도 분석
- **시간 복잡도**: $O(K \cdot (T + M))$
  - $K$는 곡 개수(최대 100), $T$는 재생 시간(최대 1439), $M$은 기억한 멜로디 길이(최대 1439)입니다.
  - 곡마다 재생 문자열을 만들고 `find`로 탐색합니다.
- **공간 복잡도**: $O(T + M)$
  - 재생 문자열과 변환된 멜로디를 저장합니다.
