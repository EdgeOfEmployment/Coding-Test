# [프로그래머스] 기둥과 보 설치 - C++ 풀이

## 1. 문제 설명
`n x n` 격자 벽면에 길이 1인 **기둥**(위쪽 방향)과 **보**(오른쪽 방향)를 설치/삭제하는 작업이 순서대로 주어질 때, 모든 작업을 수행한 뒤 구조물의 상태를 반환하는 문제입니다.

- 기둥은 **바닥 위**, **보의 한쪽 끝 위**, 또는 **다른 기둥 위**에 있어야 합니다.
- 보는 **한쪽 끝이 기둥 위**에 있거나, **양쪽 끝이 다른 보와 동시에 연결**되어 있어야 합니다.
- 설치/삭제 후 규칙을 만족하지 않으면 해당 작업은 무시됩니다.
- 결과는 x 오름차순, x가 같으면 y 오름차순, x·y가 모두 같으면 기둥이 보보다 앞에 오도록 정렬합니다.

---

## 2. 제한사항
- 5 ≤ `n` ≤ 100
- 1 ≤ `build_frame`의 길이 ≤ 1,000
- `build_frame`의 원소는 `[x, y, a, b]` (`a`: 0 기둥 / 1 보, `b`: 0 삭제 / 1 설치)
- 벽면을 벗어나거나 바닥에 보를 설치하는 경우, 겹쳐 설치하거나 없는 구조물을 삭제하는 경우는 주어지지 않습니다.

---

## 3. 핵심 풀이 접근 방식 (시뮬레이션)

1. **기둥/보를 2차원 배열로 관리**
   - `pillar[x][y]`, `beam[x][y]`로 해당 교차점에서 시작하는 구조물의 존재 여부를 저장합니다.
   - 보의 오른쪽 끝 `x+1` 접근을 위해 `n+2` 크기로 만듭니다.

2. **"일단 적용 후 검증, 실패 시 되돌리기"**
   - 설치/삭제를 우선 적용한 뒤 전체 구조물이 규칙을 만족하는지 `valid`로 검사합니다.
   - 불만족하면 이전 값으로 복구합니다. 설치·삭제 모두 같은 로직으로 처리되어 구현이 단순합니다.

3. **전체 검증 조건**
   - 기둥: `y == 0` 또는 `pillar[x][y-1]` 또는 `beam[x][y]` 또는 `beam[x-1][y]`
   - 보: `pillar[x][y-1]` 또는 `pillar[x+1][y-1]` 또는 (`beam[x-1][y]` && `beam[x+1][y]`)

4. **정렬 순서대로 출력**
   - `x → y` 순으로 순회하며 기둥을 먼저 담으면 별도 정렬이 필요 없습니다.

## 4. C++ 정답 코드

```cpp
#include <string>
#include <vector>

using namespace std;

// 현재 구조물 전체가 규칙을 만족하는지 검사
bool valid(int n, const vector<vector<int>>& pillar, const vector<vector<int>>& beam) {
    for (int x = 0; x <= n; x++) {
        for (int y = 0; y <= n; y++) {
            // 기둥: 바닥 위 / 보의 한쪽 끝 위 / 다른 기둥 위
            if (pillar[x][y]) {
                bool ok = (y == 0)
                    || (y > 0 && pillar[x][y - 1])
                    || beam[x][y]
                    || (x > 0 && beam[x - 1][y]);
                if (!ok) return false;
            }
            // 보: 한쪽 끝이 기둥 위 / 양쪽 끝이 다른 보와 연결
            if (beam[x][y]) {
                bool ok = (y > 0 && pillar[x][y - 1])
                    || (y > 0 && pillar[x + 1][y - 1])
                    || (x > 0 && beam[x - 1][y] && beam[x + 1][y]);
                if (!ok) return false;
            }
        }
    }
    return true;
}

vector<vector<int>> solution(int n, vector<vector<int>> build_frame) {
    // 인덱스 0..n 까지 사용 (보의 오른쪽 끝 x+1 접근을 위해 n+2 크기)
    vector<vector<int>> pillar(n + 2, vector<int>(n + 2, 0));
    vector<vector<int>> beam(n + 2, vector<int>(n + 2, 0));

    for (const auto& f : build_frame) {
        int x = f[0], y = f[1], a = f[2], b = f[3];

        vector<vector<int>>& target = (a == 0) ? pillar : beam;
        int prev = target[x][y];
        target[x][y] = b;              // 일단 적용해 보고

        if (!valid(n, pillar, beam)) { // 조건 불만족 시 무시(되돌림)
            target[x][y] = prev;
        }
    }

    // x 오름차순, 같으면 y 오름차순, 같은 좌표면 기둥(0) 먼저
    vector<vector<int>> answer;
    for (int x = 0; x <= n; x++) {
        for (int y = 0; y <= n; y++) {
            if (pillar[x][y]) answer.push_back({x, y, 0});
            if (beam[x][y])   answer.push_back({x, y, 1});
        }
    }
    return answer;
}
```

## 5. 복잡도 분석
- **시간 복잡도**: $O(K \cdot n^2)$
  - $K$는 작업 수(최대 1,000)이며, 매 작업마다 전체 격자($n^2$, 최대 10,000)를 검증합니다. 최대 약 $10^7$ 연산입니다.
- **공간 복잡도**: $O(n^2)$
  - 기둥/보 상태 배열을 사용합니다.
