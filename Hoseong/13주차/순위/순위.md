# [프로그래머스] 순위 - C++ 풀이

## 1. 문제 설명
n명의 권투선수와 경기 결과 `results`(`[A, B]`는 A가 B를 이겼다는 의미)가 주어질 때, 일부 경기 결과가 분실되었더라도 **정확하게 순위를 매길 수 있는 선수의 수**를 구하는 문제입니다.

- A 선수가 B 선수보다 실력이 좋다면 A는 B를 항상 이깁니다. (승패는 이행적)
- 모든 경기 결과에는 모순이 없습니다.

---

## 2. 제한사항
- 선수의 수는 1명 이상 100명 이하
- 경기 결과는 1개 이상 4,500개 이하
- `results`의 각 행 `[A, B]`는 A 선수가 B 선수를 이겼다는 의미

---

## 3. 핵심 풀이 접근 방식 (그래프 / 플로이드-워셜)

1. **승패 관계 그래프 구성**
   - `win[a][b] = true`이면 a가 b를 이긴 것으로 저장합니다.

2. **플로이드-워셜로 간접 승패 채우기**
   - `win[i][k] && win[k][j]`이면 `win[i][j] = true`로 갱신합니다.
   - A가 B를, B가 C를 이겼다면 A가 C도 이긴 것이므로 직접 붙지 않은 경기 결과도 알 수 있습니다.

3. **순위 확정 판별**
   - 선수 i에 대해 `win[i][j]` 또는 `win[j][i]`인 상대 j의 수를 셉니다.
   - 나머지 `n - 1`명 모두와의 승패를 알면 자신의 순위가 정확히 결정됩니다.

---

## 4. C++ 정답 코드

```cpp
#include <string>
#include <vector>

using namespace std;

int solution(int n, vector<vector<int>> results) {
    // win[a][b] = true 이면 a가 b를 이긴 것 (직접 또는 간접)
    vector<vector<bool>> win(n + 1, vector<bool>(n + 1, false));

    for (auto& r : results) {
        win[r[0]][r[1]] = true;
    }

    // 플로이드-워셜로 간접 승패 관계 채우기
    for (int k = 1; k <= n; k++) {
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= n; j++) {
                if (win[i][k] && win[k][j]) {
                    win[i][j] = true;
                }
            }
        }
    }

    int answer = 0;
    for (int i = 1; i <= n; i++) {
        int known = 0;
        for (int j = 1; j <= n; j++) {
            if (i != j && (win[i][j] || win[j][i])) {
                known++;
            }
        }
        // 나머지 n-1명과의 관계를 모두 알면 순위가 확정됨
        if (known == n - 1) {
            answer++;
        }
    }

    return answer;
}
```

---

## 5. 복잡도 분석
- **시간 복잡도**: $O(N^3)$
  - 플로이드-워셜의 3중 반복문이 지배적이며, $N \le 100$이므로 충분히 통과합니다.
- **공간 복잡도**: $O(N^2)$
  - $(N+1) \times (N+1)$ 크기의 승패 배열을 사용합니다.
