# [프로그래머스] 광물 캐기 - C++ 풀이

## 1. 문제 설명
마인은 다이아몬드, 철, 돌 곡괭이를 사용하여 주어진 광물들을 순서대로 캐려고 합니다. 각 곡괭이는 종류에 관계없이 5개의 광물을 캔 후 파괴되며, 캐는 광물 종류와 곡괭이 종류에 따라 소모되는 피로도가 다릅니다.

최소한의 피로도로 모든 광물을 캘 수 있도록 곡괭이를 효율적으로 선택하는 알고리즘을 구현하는 문제입니다.

---

## 2. 제한사항
- `picks`: `[dia, iron, stone]` (0 ≤ dia, iron, stone ≤ 5)
- `minerals`: 5 ≤ minerals의 길이 ≤ 50
- 광물은 주어진 순서대로만 캘 수 있습니다.
- 한 번 선택한 곡괭이는 5개를 연속해서 다 쓸 때까지 사용해야 합니다.

---

## 3. 핵심 풀이 접근 방식 (그리디 알고리즘)

1. **광물 수 제한 (`resize`)**
   - 갖고 있는 곡괭이 전체로 캘 수 있는 최대 광물 수는 `(곡괭이 총합) * 5`개입니다.
   - 곡괭이가 부족하여 어차피 캘 수 없는 뒤쪽 광물들은 미리 잘라내어야 합니다. (미리 잘라내지 않으면 캘 수 없는 뒤쪽 광물의 가치가 앞쪽 곡괭이 선택에 영향을 주는 오류가 발생합니다.)

2. **5개씩 그룹화 (`Chunking`)**
   - 광물은 5개씩 연속으로 파내므로 5개 단위로 묶음을 만듭니다.
   - 각 묶음별로 **가장 최악의 경우(돌 곡괭이를 썼을 때)의 피로도 합**을 계산합니다.

3. **정렬 및 곡괭이 할당**
   - 돌 곡괭이 기준 피로도가 가장 높은(즉, 다이아몬드나 철이 많이 포함된) 묶음부터 내림차순 정렬합니다.
   - 피로도가 높은 묶음부터 가장 좋은 곡괭이(`다이아몬드` -> `철` -> `돌`)를 순서대로 투입합니다.

## 4. C++ 정답 코드

```cpp
#include <string>
#include <vector>
#include <algorithm>

using namespace std;

// 돌 곡괭이 기준 피로도 계산
int getFatigue(const string& m) {
    if (m == "diamond") return 25;
    if (m == "iron") return 5;
    return 1;
}

int solution(vector<int> picks, vector<string> minerals) {
    int answer = 0;

    // 1. 보유한 곡괭이로 캘 수 있는 최대 광물 개수 제한
    int maxMine = (picks[0] + picks[1] + picks[2]) * 5;
    if (minerals.size() > maxMine) {
        minerals.resize(maxMine);
    }

    // 2. 5개씩 묶어서 그룹(chunk) 생성 및 피로도 합산
    vector<pair<int, vector<string>>> chunks;
    for (size_t i = 0; i < minerals.size(); i += 5) {
        vector<string> chunk;
        int fatigue = 0;

        for (size_t j = i; j < i + 5 && j < minerals.size(); j++) {
            chunk.push_back(minerals[j]);
            fatigue += getFatigue(minerals[j]);
        }
        chunks.push_back({fatigue, chunk});
    }

    // 3. 돌 곡괭이 기준 피로도가 높은 그룹 순으로 내림차순 정렬
    sort(chunks.begin(), chunks.end(), [](const auto& a, const auto& b) {
        return a.first > b.first;
    });

    // 4. 피로도가 큰 그룹부터 좋은 곡괭이(다이아 -> 철 -> 돌) 우선 할당
    for (const auto& c : chunks) {
        int pIndex = -1;
        if (picks[0] > 0) pIndex = 0;      // 다이아 곡괭이
        else if (picks[1] > 0) pIndex = 1; // 철 곡괭이
        else if (picks[2] > 0) pIndex = 2; // 돌 곡괭이
        else break;                        // 사용할 곡괭이가 없음

        picks[pIndex]--;

        // 선택된 곡괭이로 해당 묶음 캐기
        for (const string& m : c.second) {
            if (pIndex == 0) { // 다이아 곡괭이
                answer += 1;
            } else if (pIndex == 1) { // 철 곡괭이
                if (m == "diamond") answer += 5;
                else answer += 1;
            } else { // 돌 곡괭이
                if (m == "diamond") answer += 25;
                else if (m == "iron") answer += 5;
                else answer += 1;
            }
        }
    }

    return answer;
}
```

## 5. 복잡도 분석
- **시간 복잡도**: $O(N \log N)$
  - 여기서 $N$은 묶음의 개수이며 최대 10개입니다 ($50 \div 5$).
  - 따라서 정렬에 소요되는 시간이 극히 적어 실질적으로 $O(1)$에 가깝게 동작합니다.
- **공간 복잡도**: $O(N)$
  - 광물을 5개씩 묶어서 저장하는 추가 메모리가 요구됩니다.
