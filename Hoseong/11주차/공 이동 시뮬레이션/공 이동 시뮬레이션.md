# [프로그래머스] 공 이동 시뮬레이션 (C++)

## 1. 문제 개요
- **출처**: 월간 코드 챌린지 시즌3
- **난이도**: Level 3
- **주요 개념**: 역방향 추적 (Reverse Tracking), 범위 업데이트

---

## 2. 접근 방식 및 풀이 알고리즘

### 왜 역방향 추적인가?
- 격자 크기: $1 \le n, m \le 10^9$
- 쿼리 개수: $1 \le K \le 200,000$

모든 좌표에서 순방향 시뮬레이션을 수행하려면 $O(n \times m \times K)$의 시간이 소요되어 **시간 초과**가 발생합니다.

반면, **최종 도착지점 $(x, y)$에서 시작하여 쿼리를 역순으로 추적**하면 가능한 출발점의 행 범위 $[r_1, r_2]$와 열 범위 $[c_1, c_2]$를 단 $O(K)$ 만에 구할 수 있습니다.

---

### 역방향 이동 규칙

초기 범위 설정:
- $r_1 = r_2 = x$
- $c_1 = c_2 = y$

쿼리를 **뒤에서부터(역순)** 탐색하면서 각 명령을 반대로 적용합니다.

| 방향 코드 (`command`) | 원래 이동 | 역방향 동작 | 처리 로직 |
| :--- | :--- | :--- | :--- |
| **0** | 왼쪽으로 $dx$ 이동 | 오른쪽으로 $dx$ 이동 | - $c_1 \neq 0$ 이면 $c_1 = c_1 + dx$<br>- $c_2 = \min(m - 1, c_2 + dx)$ |
| **1** | 오른쪽으로 $dx$ 이동 | 왼쪽으로 $dx$ 이동 | - $c_2 \neq m - 1$ 이면 $c_2 = c_2 - dx$<br>- $c_1 = \max(0, c_1 - dx)$ |
| **2** | 위쪽으로 $dx$ 이동 | 아래쪽으로 $dx$ 이동 | - $r_1 \neq 0$ 이면 $r_1 = r_1 + dx$<br>- $r_2 = \min(n - 1, r_2 + dx)$ |
| **3** | 아래쪽으로 $dx$ 이동 | 위쪽으로 $dx$ 이동 | - $r_2 \neq n - 1$ 이면 $r_2 = r_2 - dx$<br>- $r_1 = \max(0, r_1 - dx)$ |

#### 예외 처리 (격자 이탈)
역추적 진행 중 범위가 격자를 완전히 벗어나는 경우($r_1 \ge n$, $r_2 < 0$, $c_1 \ge m$, $c_2 < 0$), 해당 목적지 $(x, y)$에 도달할 수 있는 출발점이 존재하지 않는 것이므로 **`0`**을 반환합니다.

## 3. C++ 코드 Implementation

```cpp
#include <vector>
#include <algorithm>

using namespace std;

long long solution(int n, int m, int x, int y, vector<vector<int>> queries) {
    // 0-indexed 좌표 및 범위 설정 (오버플로우 방지를 위해 long long 사용)
    long long r1 = x, r2 = x;
    long long c1 = y, c2 = y;
    
    // 쿼리를 역순으로 탐색
    for (int i = queries.size() - 1; i >= 0; --i) {
        int dir = queries[i][0];
        long long dx = queries[i][1];
        
        if (dir == 0) { // 좌측 이동 -> 역동작: 우측 이동
            if (c1 != 0) c1 += dx;
            c2 = min((long long)m - 1, c2 + dx);
            if (c1 >= m) return 0;
        } 
        else if (dir == 1) { // 우측 이동 -> 역동작: 좌측 이동
            if (c2 != m - 1) c2 -= dx;
            c1 = max(0LL, c1 - dx);
            if (c2 < 0) return 0;
        } 
        else if (dir == 2) { // 상향 이동 -> 역동작: 하향 이동
            if (r1 != 0) r1 += dx;
            r2 = min((long long)n - 1, r2 + dx);
            if (r1 >= n) return 0;
        } 
        else if (dir == 3) { // 하향 이동 -> 역동작: 상향 이동
            if (r2 != n - 1) r2 -= dx;
            r1 = max(0LL, r1 - dx);
            if (r2 < 0) return 0;
        }
    }
    
    // 가능한 출발점의 개수 (사각형 영역의 넓이)
    return (r2 - r1 + 1) * (c2 - c1 + 1);
}
```

---

## 4. 복잡도 분석

- **시간 복잡도**: $O(K)$
  - $K$는 쿼리의 개수(최대 200,000)입니다. 쿼리 배열을 1회 역순으로 순회하므로 $10^9$ 크기의 격자 크기와 상관없이 매우 빠르게 수행됩니다.
- **공간 복잡도**: $O(1)$
  - 별도의 가변 배열을 사용하지 않고 범위를 나타내는 변수 $r_1, r_2, c_1, c_2$ 만 사용하므로 메모리 사용량이 최소화됩니다.
