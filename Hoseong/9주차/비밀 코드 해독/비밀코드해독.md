# 🔐 [프로그래머스] 비밀 코드 해독 풀이

> **핵심 아이디어 : 가능한 코드 후보를 완전 탐색하고, 각 후보를 비트마스크로 빠르게 검증한다**

---

## 문제 분석

- `1 ~ n` 중 **서로 다른 5개**의 수로 이루어진 비밀 코드가 존재한다.
- `q[i]`는 진우가 부른 5개의 수, `ans[i]`는 그 시도에 대한 응답이다.
- 응답 규칙: `q[i]`에 포함된 수 중 **실제 비밀 코드에 들어 있는 수의 개수**가 `ans[i]`이다.
- 주어진 모든 시도-응답 쌍을 **모두 만족하는** 비밀 코드 후보의 개수를 구한다.

`n`이 작기 때문에(`n ≤ 30`) 가능한 모든 코드 조합을 직접 만들어 검사하는

**완전 탐색(brute force)** 이 성립한다.

---

## 접근 방법

### 1. 후보의 수

`1 ~ n`에서 5개를 고르는 경우의 수는 `C(n, 5)`.

`n = 30`일 때 `C(30, 5) = 142,506`으로, 전부 만들어도 부담이 없다.

### 2. 검증을 빠르게 — 비트마스크

각 시도 `q[i]`를 **비트마스크**로 미리 변환해 둔다.

- `qmask[i]`의 `v`번째 비트가 1이면 → 시도 `q[i]`에 수 `v`가 포함됨.

후보 코드 `{a, b, c, d, e}`도 같은 방식으로 `mask`를 만든다.

그러면 "후보와 시도가 공통으로 가진 수의 개수"는

```
popcount(mask & qmask[i])
```

한 번의 AND 연산 + 비트 카운트로 즉시 구해진다.

이 값이 `ans[i]`와 다르면 그 후보는 탈락, 모든 `i`에서 일치하면 정답 후보로 카운트한다.

> `n`이 최대 30이라 비트가 32개를 넘을 수 있으므로 `long long`(64비트)과
> `1LL << v`, `__builtin_popcountll`을 사용한다.

---

## 알고리즘

1. 모든 시도 `q[i]`를 `qmask[i]` 비트마스크로 변환.
2. `a < b < c < d < e`가 되도록 5중 for문으로 서로 다른 5개 수의 모든 조합 생성.
3. 각 조합을 `mask`로 만든 뒤, 모든 시도에 대해
   `popcount(mask & qmask[i]) == ans[i]` 인지 검사.
4. 전부 통과한 조합의 수를 세어 반환.

---

## 시간 복잡도

- 후보 조합 수 : `C(n, 5)` ≈ 최대 약 `1.4 * 10^5`
- 후보마다 시도 `m`개 검증 : `O(m)` (`m ≤ 10`)
- 비트 연산은 상수 시간

전체 : **`O(C(n,5) * m)`** ≈ `10^6` 수준으로 매우 여유롭다.

---

## 구현 코드

```cpp
#include <string>
#include <vector>
using namespace std;

int solution(int n, vector<vector<int>> q, vector<int> ans) {
    int m = q.size();

    // 각 시도(q[i])를 비트마스크로 변환
    vector<long long> qmask(m, 0);
    for (int i = 0; i < m; i++) {
        for (int v : q[i]) {
            qmask[i] |= (1LL << v);
        }
    }

    int answer = 0;

    // 1~n 중 서로 다른 5개(a<b<c<d<e)를 모두 시도
    for (int a = 1; a <= n - 4; a++)
    for (int b = a + 1; b <= n - 3; b++)
    for (int c = b + 1; c <= n - 2; c++)
    for (int d = c + 1; d <= n - 1; d++)
    for (int e = d + 1; e <= n; e++) {
        long long mask = (1LL << a) | (1LL << b) | (1LL << c)
                       | (1LL << d) | (1LL << e);

        bool ok = true;
        for (int i = 0; i < m; i++) {
            // 후보와 시도가 공유하는 수의 개수
            int cnt = __builtin_popcountll(mask & qmask[i]);
            if (cnt != ans[i]) {   // 응답과 다르면 탈락
                ok = false;
                break;
            }
        }

        if (ok) answer++;
    }

    return answer;
}
```
