# 🪖 [프로그래머스] 부대복귀 풀이

> **핵심 아이디어 : 목적지에서 한 번만 BFS를 돌려 모든 지역까지의 최단 거리를 구한다**

---

## 문제 분석

- `n`개의 지역이 있고, `roads`는 두 지역을 잇는 **양방향** 도로 목록이다.
- 여러 부대가 각각 `sources[i]` 지역에 있고, 모두 `destination` 지역으로 복귀해야 한다.
- 각 부대에 대해 `destination`까지 이동해야 하는 **최소 도로 수**를 구한다.
- 도달할 수 없으면 `-1`.

즉, **가중치가 없는(모든 간선 비용 = 1) 무방향 그래프에서의 최단 경로** 문제이다.

---

## 접근 방법

### 1. source마다 BFS를 돌리면?

각 `source`에서 `destination`까지 BFS를 돌리는 방법을 먼저 떠올릴 수 있다.

하지만 `sources`의 길이가 최대 `10만`이고 지역 수도 `10만`, 도로 수도 `50만`이므로

`sources` 개수만큼 BFS를 반복하면 `O(sources * (V + E))`로 시간 초과가 난다.

### 2. 목적지에서 역방향으로 한 번만 BFS

도로가 **양방향**이라는 점이 핵심이다.

`A → destination`까지의 최단 거리는 `destination → A`까지의 최단 거리와 같다.

따라서 **`destination`을 시작점으로 BFS를 딱 한 번** 수행하면

모든 지역까지의 최단 거리 `dist[]`를 한꺼번에 구할 수 있다.

그 다음 각 `source`에 대해 `dist[source]` 값을 그대로 읽어 주기만 하면 된다.

- 가중치가 없으므로 다익스트라 없이 **BFS만으로 최단 거리**가 보장된다.
- BFS에서 처음 방문하는 순간이 곧 최단 거리이다.

---

## 알고리즘

1. 인접 리스트 `graph` 구성 (양방향이므로 `a↔b` 둘 다 추가).
2. `dist` 배열을 `-1`로 초기화 (미방문 = 도달 불가 상태).
3. `dist[destination] = 0`으로 두고 `destination`을 큐에 넣는다.
4. BFS: 큐에서 꺼낸 노드의 인접 노드 중 미방문(`dist == -1`)이면
   `dist[next] = dist[cur] + 1`로 갱신 후 큐에 push.
5. 모든 `source`에 대해 `dist[source]`를 answer에 담아 반환.
   (도달 불가한 지역은 `-1`이 그대로 남아 있으므로 별도 처리 불필요.)

---

## 시간 복잡도

- 그래프 구성 : `O(E)`
- BFS : `O(V + E)`
- 정답 수집 : `O(sources)`

전체 : **`O(V + E + sources)`** — 한 번의 BFS로 해결되므로 충분히 빠르다.

---

## 구현 코드

```cpp
#include <string>
#include <vector>
#include <queue>

using namespace std;

vector<int> solution(int n, vector<vector<int>> roads, vector<int> sources, int destination) {
    vector<int> answer;

    // 1. 양방향 인접 리스트
    vector<vector<int>> graph(n + 1);
    for (auto& r : roads) {
        int a = r[0], b = r[1];
        graph[a].push_back(b);
        graph[b].push_back(a);
    }

    // 2. destination 기준 BFS로 모든 지역까지의 최단 거리 계산
    vector<int> dist(n + 1, -1);
    dist[destination] = 0;
    queue<int> q;
    q.push(destination);

    while (!q.empty()) {
        int cur = q.front();
        q.pop();
        for (int next : graph[cur]) {
            if (dist[next] == -1) {          // 처음 방문 = 최단 거리
                dist[next] = dist[cur] + 1;
                q.push(next);
            }
        }
    }

    // 3. 각 source의 거리를 그대로 조회 (도달 불가는 -1)
    for (int s : sources) {
        answer.push_back(dist[s]);
    }

    return answer;
}
```

## 정리

| 포인트 | 내용 |
| --- | --- |
| 그래프 종류 | 무방향 · 무가중치 |
| 최단 경로 기법 | BFS (다익스트라 불필요) |
| 최적화 핵심 | source마다 BFS ❌ → **destination에서 1회 BFS** ⭕ |
| 도달 불가 처리 | `dist` 초기값 `-1`을 그대로 반환 |
