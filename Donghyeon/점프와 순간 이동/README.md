## 풀이와 생각

### 접근 방법

- 비트 연산(이진수 변환) 문제로 치환해서 풀이
- 얼핏 보면 BFS/DP로 0부터 N까지의 최소 점프 횟수를 구해야 할 것 같지만, 문제를 거꾸로(도착점 N에서 출발점 0으로) 생각하면 규칙이 드러남
  - 순간이동은 "현재 위치 × 2"이므로, 역방향으로 보면 위치가 짝수일 때 2로 나누는 것 = 순간이동을 거꾸로 재생하는 것
  - 위치가 홀수라면 짝수로 만들 방법이 점프(1칸 이동)밖에 없으므로, 그 지점에서는 반드시 건전지 1을 소모하는 점프가 있었어야 함
- 즉 N을 2로 계속 나누면서, 나머지가 1(홀수)일 때마다 건전지 사용량을 1씩 증가시키면 됨
- 이는 결국 N을 이진수로 표현했을 때 1의 개수(popcount)를 세는 것과 동일

### 코드 해설

- `n % 2`: 현재 최하위 비트가 1(홀수)이면 그 단계에서 점프가 필요했다는 뜻이므로 `ans`에 더함
- `n = Math.floor(n / 2)`: 순간이동을 거꾸로 되감는 연산(오른쪽으로 1비트 시프트)
- 이 과정을 n이 0이 될 때까지 반복하면, 이진수의 1의 개수 = 최소 점프(건전지) 횟수가 나옴

### 복잡도

- O(log N) — N이 최대 10억이어도 비트 수는 약 30개뿐이라 매우 빠름 (성능 요약에서 시간 0.10ms로도 확인됨)

### 느낀 점

- 겉보기엔 그래프 탐색/DP 문제처럼 보이지만, 실제로는 이진수와 비트 연산에 대한 통찰이 핵심인 문제였음
- "위치를 2배로 만든다"는 연산을 보면 이진수 시프트를 먼저 떠올리는 습관을 들이면 좋겠다고 생각함
- 코드 자체는 popcount 구현과 동일하므로, 이후 "2배 연산"이 핵심 조건으로 등장하는 문제를 만나면 비트 관점으로 먼저 접근해볼 것
