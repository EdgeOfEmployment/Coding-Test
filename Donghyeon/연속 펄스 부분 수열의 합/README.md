### 문제 설명

<p>어떤 수열의 연속 부분 수열에 같은 길이의 펄스 수열을 각 원소끼리 곱하여 연속 펄스 부분 수열을 만들려 합니다. 펄스 수열이란 [1, -1, 1, -1 …] 또는 [-1, 1, -1, 1 …] 과 같이 1 또는 -1로 시작하면서 1과 -1이 번갈아 나오는 수열입니다.<br>
예를 들어 수열 [2, 3, -6, 1, 3, -1, 2, 4]의 연속 부분 수열 [3, -6, 1]에 펄스 수열 [1, -1, 1]을 곱하면 연속 펄스 부분수열은 [3, 6, 1]이 됩니다. 또 다른 예시로 연속 부분 수열 [3, -1, 2, 4]에 펄스 수열 [-1, 1, -1, 1]을 곱하면 연속 펄스 부분수열은 [-3, -1, -2, 4]이 됩니다.<br>
정수 수열 <code>sequence</code>가 매개변수로 주어질 때, 연속 펄스 부분 수열의 합 중 가장 큰 것을 return 하도록 solution 함수를 완성해주세요.</p>

<h5>입출력 예 설명</h5>

<p>주어진 수열의 연속 부분 수열 [3, -6, 1]에 펄스 수열 [1, -1, 1]을 곱하여 연속 펄스 부분 수열 [3, 6, 1]을 얻을 수 있고 그 합은 10으로서 가장 큽니다.</p>

### 풀이

구간 `[L, R]`마다 펄스를 앞에서부터 새로 매길 필요 없이, **수열 전체에 인덱스의 짝/홀에 따라 고정된 부호(+1, -1)를 미리 곱해둔 누적합**만으로 풀 수 있음

1. `pulse = i % 2 === 0 ? 1 : -1`로 인덱스별 고정 부호를 정하고, `prefixSum`에 `sequence[i] * pulse`를 누적한다.
2. 매 인덱스마다 지금까지의 `prefixSum` 중 최댓값(`maxPrefix`)과 최솟값(`minPrefix`)을 갱신한다.
3. 최종 답은 `maxPrefix - minPrefix`.

### 생각

처음 보면 "부분 수열마다 펄스가 항상 1(또는 -1)부터 새로 시작"하니 구간마다 부호를 다시 매겨야 할 것 같지만, 실제로는 전역 인덱스 기준으로 고정된 부호를 매겨도 상관없다는 걸 알아채는게 핵심..ㅋㅋ

어떤 구간 `[L, R]`에 대해 "L에서 부호 +1로 시작하는 펄스"를 곱한 합은, 전역 누적합 기준으로 `prefixSum[R] - prefixSum[L-1]` 그대로다(전역 부호를 인덱스 패리티로 고정해뒀기 때문에 구간 내에서도 +1, -1이 번갈아 나오는 성질이 그대로 유지된다). 반대로 "L에서 부호 -1로 시작하는 펄스"를 곱한 합은 그 값의 부호만 뒤집은 것과 같으므로 `prefixSum[L-1] - prefixSum[R]`이 가능함

즉 하나의 전역 누적합 배열만으로 두 가지 펄스 방향(+1 시작 / -1 시작)을 모두 표현할 수 있고, 각각은 "어떤 두 지점의 누적합 차이"와 "그 차이의 부호를 뒤집은 값"이므로, 전체 구간에서 `prefixSum`의 최댓값과 최솟값의 차이(`maxPrefix - minPrefix`)를 구하면 두 방향을 모두 고려한 최댓값이 자동으로 나오게됨
구간마다 DP를 돌리거나 두 phase를 따로 두 번 순회할 필요 없이 한 번의 순회로 끝나는 게 이 풀이의 재밌는점(수학 좋아!)
