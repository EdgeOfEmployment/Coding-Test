### 문제 설명

<p>프로그래머스 다트 협회에서는 매년마다 새로운 특수 룰으로 다트 대회를 개최합니다. 이번 대회의 룰은 "카운트 다운"으로 "제로원" 룰의 변형 룰입니다.<br>
"카운트 다운"은 게임이 시작되면 무작위로 점수가 정해지고, 다트를 던지면서 점수를 깎아서 정확히 0점으로 만드는 게임입니다. 단, 남은 점수보다 큰 점수로 득점하면 버스트가 되며 실격 합니다.</p>

<p>다음 그림은 다트 과녁입니다.<br>

<p>다트 과녁에는 1 부터 20 까지의 수가 하나씩 있고 각 수마다 "싱글", "더블", "트리플" 칸이 있습니다. "싱글"을 맞히면 해당 수만큼 점수를 얻고 "더블"을 맞히면 해당 수의 두 배만큼 점수를 얻고 "트리플"을 맞히면 해당 수의 세 배만큼 점수를 얻습니다. 가운데에는 "불"과 "아우터 불"이 있는데 "카운트 다운" 게임에서는 구분 없이 50점을 얻습니다.</p>

<p>대회는 토너먼트로 진행되며 한 게임에는 두 선수가 참가하게 됩니다. 게임은 두 선수가 교대로 한 번씩 던지는 라운드 방식으로 진행됩니다. 가장 먼저 0점을 만든 선수가 승리하는데 만약 두 선수가 같은 라운드에 0점을 만들면 두 선수 중 "싱글" 또는 "불"을 더 많이 던진 선수가 승리하며 그마저도 같다면 선공인 선수가 승리합니다.</p>

<p>다트 실력에 자신 있던 종호는 이 대회에 출전하기로 하였습니다. 최소한의 다트로 0점을 만드는 게 가장 중요하고, 그러한 방법이 여러가지가 있다면 "싱글" 또는 "불"을 최대한 많이 던지는 방법을 선택해야 합니다.</p>

<p>목표 점수 <code>target</code>이 매개변수로 주어졌을 때 최선의 경우 던질 다트 수와 그 때의 "싱글" 또는 "불"을 맞춘 횟수(합)를 순서대로 배열에 담아 return 하도록 solution 함수를 완성해 주세요.</p>

### 풀이

동전 교환 문제(Coin Change)와 유사한 구조의 다이나믹 프로그래밍으로 해결.

1. `dp[i] = [i점을 만드는 데 필요한 최소 다트 수, 그때의 싱글/불 최대 횟수]`로 정의하고, `dp[0] = [0, 0]`에서 시작.
2. 다트 한 발로 얻을 수 있는 모든 경우의 수(싱글 1~20, 더블 2~40, 트리플 3~60, 불 50)를 `[점수, 싱글/불 보너스 여부]` 쌍으로 미리 나열.
3. 1점부터 `target`까지 순서대로 `dp[i]`를 채우는데, 각 점수 `score`에 대해 `dp[i - score]`에 그 한 발을 더했을 때
    - 다트 수가 더 적으면 무조건 갱신하고,
    - 다트 수가 같다면 싱글/불 횟수가 더 많은 쪽으로 갱신.
4. 최종적으로 `dp[target]`이 "최소 다트 수, 그중 싱글/불을 최대한 많이 던진 횟수"가 되어 그대로 반환.

"최소 개수 우선, 개수가 같으면 싱글/불 최대"라는 두 단계 우선순위를 `dp` 값에 튜플로 함께 들고 다니며 비교하는 것이 핵심.

#### 예시로 보는 dp 채워지는 과정 (target = 58)

`dp[i]`는 "i점을 만드는 [최소 다트 수, 싱글/불 최대 횟수]"를 의미
`dp[58] = [2, 2]`가 나오기까지 관련된 상태만 확인

| i (점수) | 이번에 던진 다트          | 참조한 이전 상태 `dp[i-score]` | 갱신 후 `dp[i]` | 의미                              |
| -------- | ------------------------- | ------------------------------ | --------------- | --------------------------------- |
| 0        | (시작)                    | -                              | `[0, 0]`        | 다트를 아직 던지지 않은 상태      |
| 8        | 싱글 8 (score=8, bonus=1) | `dp[0] = [0, 0]`               | `[1, 1]`        | 다트 1개로 8점, 싱글 1회          |
| 58       | 불 (score=50, bonus=1)    | `dp[8] = [1, 1]`               | `[2, 2]`        | 다트 2개로 58점, 싱글/불 합계 2회 |

즉 `dp[58]`을 채울 때 `throws` 목록에 있는 "50점(불)" 후보를 만나면, `dp[58 - 50] = dp[8] = [1, 1]`에 이 한 발(다트 +1, 보너스 +1)을 더해 `[2, 2]`를 얻음.
이 값은 다른 어떤 조합(예: 싱글로만 58번 던지는 `[58, 58]`, 더블 위주 조합 등)보다 다트 수가 적으므로 `dp[58]`로 최종 채택
