# 점프와 순간 이동

- 문제 링크: [https://school.programmers.co.kr/learn/courses/30/lessons/12980](https://school.programmers.co.kr/learn/courses/30/lessons/12980)
- 사용 알고리즘: 그리디, 역방향 탐색, 이진수

## 1. 문제 이해

현재 위치에서 다음 두 가지 방법으로 `N`까지 이동할 수 있다.

- `K`칸 점프: 건전지 `K`만큼 사용
- 현재 거리의 2배로 순간이동: 건전지를 사용하지 않음

건전지 사용량의 최솟값을 구해야 한다.

## 2. 역방향 그리디 풀이

`0`에서 `N`으로 이동하는 대신 `N`에서 `0`으로 거꾸로 이동한다.

- `N`이 짝수이면 `N // 2`: 순간이동을 거꾸로 적용한 것이므로 건전지를 사용하지 않는다.
- `N`이 홀수이면 `N - 1`: 1칸 점프가 필요하므로 건전지 사용량을 1 증가시킨다.

짝수일 때는 건전지를 사용하지 않는 나누기 2를 선택하는 것이 유리하고, 홀수일 때는 2로 나누기 위해 반드시 1을 빼야 한다.

```python
def solution(n):
    answer = 0

    while n > 0:
        if n % 2 == 0:
            n //= 2
        else:
            n -= 1
            answer += 1

    return answer
```

## 3. 이진수를 이용한 풀이

역방향으로 이동할 때 다음 규칙이 성립한다.

- 짝수를 2로 나누면 이진수의 마지막 `0`이 사라진다.
- 홀수에서 1을 빼면 이진수의 마지막 `1`이 사라지고 건전지를 1 사용한다.

따라서 건전지 사용량은 `N`을 이진수로 바꿨을 때 `1`의 개수와 같다.

예를 들어 `6`의 이진수는 `110`이고, `1`이 2개이므로 정답은 2이다.

```python
def solution(n):
    return bin(n).count('1')
```

### `bin(n).count('1')`의 의미

```python
bin(6)             # '0b110'
bin(6).count('1')  # 2
```

- `bin(n)`: 정수 `n`을 `0b`로 시작하는 이진수 문자열로 변환한다.
- `.count('1')`: 변환된 문자열에 문자 `'1'`이 몇 개 있는지 센다.

## 4. 시간 복잡도

`N`을 반복해서 2로 나누거나 이진수로 변환하므로 두 풀이 모두 시간 복잡도는 `O(log N)`이다.

- 역방향 그리디 풀이: 시간 `O(log N)`, 공간 `O(1)`
- `bin` 풀이: 시간 `O(log N)`, 이진수 문자열을 저장하므로 공간 `O(log N)`

## 5. AI를 통해 도움받은 부분

- DP가 아니라 역방향 그리디로 접근할 수 있다는 점
- 이진수에서 `1`의 개수가 최소 건전지 사용량과 같다는 원리
- `bin(n).count('1')`을 이용한 간단한 구현
