## 마법의 엘리베이터

지난주의 **「점프와 순간이동」** 문제와 유사하게, 매 자릿수에서 현재 상황에 가장 유리한 선택을 하는 **그리디 문제**라고 판단했다.

### 1차 풀이

처음에는 현재 일의 자리 숫자를 기준으로 다음과 같이 처리하려고 했다.

- 일의 자리가 **5보다 작으면 아래로 이동**
- 일의 자리가 **5보다 크면 위로 이동**

즉, `storey % 10`으로 일의 자리 숫자를 확인한 뒤 각 자릿수를 하나씩 처리하는 방식이다.

### 문제점 1. 일의 자리가 5인 경우를 고려하지 못함

일의 자리가 정확히 `5`라면 위로 이동하든 아래로 이동하든 현재 자리에서 필요한 이동 횟수는 동일하게 5번이다. 따라서 **다음 자릿수까지 확인해야 최적의 방향을 결정할 수 있다.**

예를 들어,

- `35`는 아래로 이동하면 `30`, 위로 이동하면 `40`이 되므로 **아래로 이동하는 것이 유리하다.**
- `95`는 아래로 이동하면 `90`, 위로 이동하면 `100`이 되므로 **위로 이동하는 것이 유리하다.**

따라서 현재 자리 숫자가 `5`인 경우에는 다음 자리 숫자가 `5` 이상인지 여부까지 확인하여 방향을 결정해야 한다.

### 문제점 2. 현재 자릿수를 기준으로 반복문을 종료함

처음에는 현재 확인 중인 숫자가 `0`이 되면 반복문을 종료하도록 구성했다. 하지만 `304`처럼 **숫자 중간에 0이 존재하는 경우**, 아직 처리해야 할 높은 자릿수가 남아 있는데도 반복문이 종료될 수 있다.

이를 해결하기 위해 처음에는 `len(str(storey))`로 자릿수를 구한 뒤, `for`문을 사용해 자릿수만큼 반복하도록 변경했다.

하지만 이 방식에도 문제가 있었다.

예를 들어 `999`와 같이 각 자리에서 위로 이동을 선택하면 올림이 계속 발생해 최종적으로 `1000`이 된다. 즉, **처음에는 3자리였지만 처리 과정에서 새로운 자릿수가 생길 수 있다.** 따라서 처음 계산한 자릿수만큼만 반복하면 마지막에 새로 생긴 `1`을 처리하지 못할 수 있다.

결국 반복 횟수를 미리 고정하는 방식보다는, **처리해야 할 `storey` 값이 남아 있는 동안 반복하는 방식**이 더 안전하다고 판단했다.

### 최종 아이디어

각 반복에서 일의 자리 숫자를 하나씩 확인한다.

- `0~4` → 아래로 이동
- `6~9` → 위로 이동한 뒤 다음 자리에 `1`을 올림
- `5` → 다음 자리 숫자를 확인하여 위·아래 방향 결정

이후 `storey // 10`을 통해 현재 자리를 제거하고, 올림까지 반영된 `storey`가 남아 있는 동안 반복한다.

즉, 이 문제에서는 단순히 현재 자릿수만 보는 것이 아니라 **다음 자릿수와 올림으로 인해 새 자릿수가 생기는 경우까지 고려하는 것이 핵심**이다.
