# 2×n 타일링 문제 풀이 공유

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12900)

## 1. 접근법과 단순 풀이의 한계

가로 길이가 `n`, 세로 길이가 `2`인 바닥을 `2×1` 타일로 빈틈없이 채우는 경우의 수를 구하는 문제입니다. 타일은 세로로 하나를 놓거나 가로로 두 개를 쌓아 놓을 수 있으며, 정답은 `1,000,000,007`로 나눈 나머지를 반환합니다.

- **모든 배치를 직접 나열하는 접근의 한계**: 바닥이 길어질수록 가능한 배치가 빠르게 늘어나므로 모든 경우를 만들어 확인하기 어렵습니다.
- **같은 작은 문제를 반복 계산하는 접근의 한계**: 길이 `n`의 경우의 수는 길이 `n-1`과 `n-2`의 경우의 수로 구할 수 있습니다. 이전 결과를 저장하지 않으면 같은 길이의 경우의 수를 여러 번 계산하게 됩니다.
- **방향 수정**: `dp[i]`를 **가로 길이가 `i`인 바닥을 채우는 경우의 수**로 정의합니다. 가장 오른쪽을 채우는 타일의 모양에 따라 경우를 나누고, 작은 길이부터 정답을 배열에 저장하는 **동적 계획법(DP)**을 사용합니다.

## 2. 해결 코드

```python
def solution(n):
    MOD = 1_000_000_007

    # dp[i]: 가로 길이가 i인 바닥을 채우는 경우의 수
    dp = [0] * (n + 1)

    # 가장 작은 바닥의 경우의 수
    dp[1] = 1
    if n >= 2:
        dp[2] = 2

    # 마지막에 세로 타일 1개 또는 가로 타일 2개를 놓는 경우를 합산
    for i in range(3, n + 1):
        dp[i] = (dp[i - 1] + dp[i - 2]) % MOD

    return dp[n]
```

## 3. 구현 전략 및 이유

### `dp[i]`에 가로 길이별 경우의 수를 저장하는 이유

```python
dp = [0] * (n + 1)
```

`dp[i]`는 가로 길이가 `i`인 바닥을 채우는 경우의 수입니다. 예를 들어 `dp[3] = 3`이면 가로 길이 3인 바닥을 채우는 방법이 3가지라는 뜻입니다. `n + 1`칸을 만드는 이유는 인덱스 `n`까지 사용하기 위해서이며, 이 풀이에서 `dp[0]`은 사용하지 않습니다.

### 초기값을 `dp[1] = 1`, `dp[2] = 2`로 두는 이유

가로 길이가 1이면 세로 타일 하나를 놓는 방법만 있으므로 `dp[1] = 1`입니다. 가로 길이가 2이면 세로 타일 두 개를 나란히 놓거나 가로 타일 두 개를 위아래로 쌓는 방법이 있으므로 `dp[2] = 2`입니다.

```python
dp[1] = 1
if n >= 2:
    dp[2] = 2
```

`n = 1`일 때 배열에는 인덱스 2가 없으므로 `if n >= 2` 조건을 확인한 뒤 `dp[2]`에 값을 저장합니다.

### 점화식이 `dp[i] = dp[i-1] + dp[i-2]`인 이유

가로 길이 `i`인 바닥의 **가장 오른쪽 부분**을 기준으로 두 경우로 나눌 수 있습니다.

| 가장 오른쪽에 놓는 타일 | 나머지 바닥의 가로 길이 | 경우의 수 |
| --- | --- | --- |
| 세로 타일 1개 | `i-1` | `dp[i-1]` |
| 가로 타일 2개를 위아래로 쌓기 | `i-2` | `dp[i-2]` |

첫 번째 경우에는 길이 `i-1`인 바닥을 채운 뒤 오른쪽에 세로 타일 하나를 붙입니다. 두 번째 경우에는 길이 `i-2`인 바닥을 채운 뒤 오른쪽에 가로 타일 두 개를 붙입니다. 가장 오른쪽의 모양이 서로 다르므로 두 경우는 겹치지 않으며, 가능한 배치를 모두 포함합니다. 따라서 두 경우의 수를 더합니다.

```python
dp[i] = dp[i - 1] + dp[i - 2]
```

예를 들어 `dp[4] = dp[3] + dp[2] = 3 + 2 = 5`입니다.

### 작은 길이부터 반복문으로 계산하는 이유

```python
for i in range(3, n + 1):
    dp[i] = (dp[i - 1] + dp[i - 2]) % MOD
```

`dp[1]`과 `dp[2]`는 이미 알고 있으므로 길이 3부터 계산합니다. `dp[i]`를 계산하는 시점에는 필요한 `dp[i-1]`, `dp[i-2]`가 모두 배열에 저장되어 있습니다. `range(3, n + 1)`은 `n`까지 포함하도록 끝값을 `n + 1`로 지정한 것입니다.

### 매번 `1,000,000,007`로 나눈 나머지를 저장하는 이유

문제에서 정답을 `1,000,000,007`로 나눈 나머지를 요구합니다. 경우의 수가 커지므로 매 단계에서 `% MOD`를 적용해 큰 정수를 계속 다루지 않도록 합니다. 덧셈에서는 중간에 나머지를 취해도 최종 나머지가 같으므로 정답에 영향을 주지 않습니다.

### 예시 입력의 계산 과정

`n = 5`일 때 초기 배열은 `dp = [0, 1, 2, 0, 0, 0]`입니다.

| 현재 길이 `i` | 계산 | 저장되는 값 |
| --- | --- | --- |
| 3 | `dp[2] + dp[1] = 2 + 1` | `dp[3] = 3` |
| 4 | `dp[3] + dp[2] = 3 + 2` | `dp[4] = 5` |
| 5 | `dp[4] + dp[3] = 5 + 3` | `dp[5] = 8` |

최종 배열은 `[0, 1, 2, 3, 5, 8]`이므로 `dp[5]`인 **8**을 반환합니다.

### 시간 및 공간 복잡도

- **시간 복잡도**: `O(n)`. 길이 3부터 `n`까지 순회하며 각 길이의 경우의 수를 한 번씩 계산합니다.
- **공간 복잡도**: `O(n)`. 길이별 경우의 수를 저장하는 `n + 1`칸의 DP 배열을 사용합니다.
