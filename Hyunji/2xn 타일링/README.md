# 2 x n 타일링 문제 풀이 공유

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/12900)

## 1. 접근법과 단순 풀이의 한계

세로 길이가 2, 가로 길이가 `n`인 바닥을 2 x 1 타일로 빈틈없이 채우는 방법의 수를 구하는 문제입니다. 타일은 세로 또는 가로로 놓을 수 있으며, 정답을 `1,000,000,007`로 나눈 나머지를 반환해야 합니다.

- **모든 배치를 직접 만드는 완전탐색의 한계**: 매번 세로 타일 하나 또는 가로 타일 두 개를 놓는 선택을 재귀적으로 시도하면 같은 너비의 남은 바닥을 여러 번 계산합니다. `n`이 최대 60,000이므로 모든 배치를 나열하는 방식은 사용할 수 없습니다.
- **작은 바닥의 결과 재사용**: 가로 길이가 1인 바닥은 1가지, 2인 바닥은 2가지 방법으로 채울 수 있습니다. 가로 길이 `n`의 바닥을 채우는 경우를 맨 오른쪽 타일의 형태로 분류하면, 이미 구한 더 작은 바닥의 경우의 수를 합해 정답을 얻을 수 있습니다.
- **방향 수정**: 모든 배치를 생성하지 않고, 이전 두 너비의 경우의 수만 갱신하는 **동적 계획법(DP)**으로 해결합니다.

## 2. 해결 코드

```python
def solution(n):
    # 가로 길이가 1인 바닥과 2인 바닥을 채우는 방법의 수
    if n == 1:
        return 1

    prev2, prev1 = 1, 2
    MOD = 1_000_000_007

    # 마지막에 세로 타일 하나 또는 가로 타일 두 개를 놓는 경우를 합산
    for _ in range(3, n + 1):
        prev2, prev1 = prev1, (prev1 + prev2) % MOD

    return prev1
```

## 3. 구현 전략 및 이유

### 마지막 타일을 기준으로 경우를 나누는 이유

가로 길이가 `n`인 바닥의 가장 오른쪽을 채우는 형태는 두 가지입니다.

- **세로 타일 하나**: 오른쪽 한 열을 채우면 나머지 너비는 `n-1`입니다. 나머지를 채우는 방법의 수는 `dp[n-1]`입니다.
- **가로 타일 두 개**: 오른쪽 위아래에 가로 타일을 하나씩 놓으면 마지막 두 열을 채웁니다. 나머지 너비는 `n-2`이므로 방법의 수는 `dp[n-2]`입니다.

두 경우는 서로 겹치지 않고 가능한 모든 배치를 포함하므로 다음 점화식이 성립합니다.

$$
dp[n] = dp[n-1] + dp[n-2]
$$

예를 들어 `n=4`라면 `dp[4] = dp[3] + dp[2] = 3 + 2 = 5`입니다. 타일을 놓는 순서를 일일이 열거하지 않아도 됩니다.

### 초기값을 1과 2로 설정하는 이유

너비가 1이면 세로 타일 하나를 놓는 방법만 가능하므로 `dp[1]=1`입니다. 너비가 2이면 세로 타일 두 개 또는 가로 타일 두 개를 놓을 수 있으므로 `dp[2]=2`입니다. `n=1`일 때는 바로 1을 반환하여 너비 2의 초기값을 별도로 처리할 필요가 없게 했습니다.

### 리스트 대신 변수 두 개만 사용하는 이유

점화식에서 다음 값을 구할 때 필요한 것은 직전 두 값뿐입니다. `prev2`는 두 단계 전의 경우의 수, `prev1`은 한 단계 전의 경우의 수를 저장합니다. 반복문에서

```python
prev2, prev1 = prev1, (prev1 + prev2) % MOD
```

를 실행하면 두 변수가 **동시에 갱신**됩니다. 오른쪽 식은 갱신 전 값을 기준으로 계산하므로, 기존 `prev1`을 잃지 않고 다음 단계로 넘어갈 수 있습니다. 예를 들어 `(1, 2) → (2, 3) → (3, 5) → (5, 8)`로 진행됩니다. 전체 `dp` 리스트를 만들지 않아도 되어 추가 공간을 일정하게 유지합니다.

### 매 단계 나머지 연산을 하는 이유

문제에서 요구하는 값은 경우의 수를 `1,000,000,007`로 나눈 나머지입니다. 덧셈에 대해

$$
(a+b)\bmod M = ((a\bmod M)+(b\bmod M))\bmod M
$$

이 성립하므로, 중간 결과에 나머지 연산을 적용해도 최종 정답의 나머지는 달라지지 않습니다. 매번 `% MOD`를 적용하면 `n`이 커져도 계산하는 정수의 크기가 과도하게 커지지 않습니다.

### 시간 및 공간 복잡도

- **시간 복잡도**: $O(n)$ (너비 3부터 `n`까지 반복하며, 매 단계 상수 번의 연산만 수행합니다.)
- **공간 복잡도**: $O(1)$ (입력 크기와 무관하게 이전 두 경우의 수와 상수만 저장합니다.)
