# 시소 짝꿍 문제 풀이 공유

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/152996)

## 1. 접근법과 단순 풀이의 한계

시소의 좌석은 중심에서 **2m, 3m, 4m** 떨어져 있습니다. 두 사람이 서로 반대편에 앉았을 때 `몸무게 × 거리`가 같으면 시소 짝꿍입니다. 주어진 사람들 중 짝꿍이 되는 **서로 다른 두 사람의 쌍**을 세어야 합니다. 같은 몸무게를 가진 사람도 각각 다른 사람이므로 인원 수를 반영해야 합니다.

- **모든 두 사람을 비교하는 접근의 한계**: 사람 수가 최대 100,000명이므로 두 명을 고르는 조합을 전부 검사하면 최대 약 50억 쌍입니다. 각 쌍마다 좌석 조합을 확인하는 `O(n²)` 풀이는 시간 제한에 맞추기 어렵습니다.
- **몸무게가 같은 사람을 한 명으로 취급하는 접근의 한계**: `[100, 100, 100]`은 몸무게 종류가 하나여도 짝꿍은 `3 × 2 // 2 = 3`쌍입니다. 몸무게별 **인원 수**를 저장해야 합니다.
- **모든 거리 조합을 매번 확인하는 접근의 한계**: 좌석 거리는 세 가지뿐이므로 서로 다른 몸무게의 비율은 `2:3`, `1:2`, `3:4` 세 종류로 압축됩니다. 같은 몸무게끼리는 같은 거리에 앉으면 되므로 별도로 계산할 수 있습니다.
- **방향 수정**: `Counter`로 몸무게별 인원을 세고, 각 몸무게를 **가벼운 사람의 몸무게**로 고정해 짝이 되는 무거운 몸무게 세 개만 조회합니다. 이때 같은 몸무게 쌍은 조합 공식으로 한 번만 계산합니다.

## 2. 해결 코드

```python
from collections import Counter


def solution(weights):
    # 몸무게별 인원 수를 저장한다.
    counts = Counter(weights)
    answer = 0

    for weight, count in counts.items():
        # 같은 몸무게인 사람 중 서로 다른 두 명을 고르는 경우의 수
        answer += count * (count - 1) // 2

        # weight가 더 가벼운 쪽일 때 가능한 무거운 몸무게 비율
        # (가벼운 사람의 거리, 무거운 사람의 거리): (3, 2), (4, 2), (4, 3)
        for numerator, denominator in ((3, 2), (2, 1), (4, 3)):
            heavier_times = weight * numerator

            # 몸무게는 정수이므로 나누어떨어지지 않으면 짝꿍이 없다.
            if heavier_times % denominator != 0:
                continue

            heavier = heavier_times // denominator
            answer += count * counts.get(heavier, 0)

    return answer
```

## 3. 구현 전략 및 이유

### 몸무게별 인원 수를 `Counter`로 저장하는 이유

```python
counts = Counter(weights)
```

예를 들어 `weights = [100, 180, 360, 100, 270]`이라면 `counts[100] = 2`, `counts[180] = 1`입니다. 각 사람을 따로 순회하지 않고도 특정 몸무게를 가진 사람이 몇 명인지 조회할 수 있습니다. `counts.items()`를 순회하면 중복 몸무게는 한 번만 처리합니다.

### 같은 몸무게인 사람을 조합으로 세는 이유

같은 몸무게라면 양쪽에서 **같은 거리**에 앉으면 균형을 이룹니다. 몸무게가 `weight`인 사람이 `count`명일 때 서로 다른 두 사람을 고르는 방법은 다음과 같습니다.

$$
\binom{count}{2} = \frac{count(count-1)}{2}
$$

따라서 `count * (count - 1) // 2`를 더합니다. 예를 들어 100인 사람이 3명이면 `(1번, 2번)`, `(1번, 3번)`, `(2번, 3번)`의 3쌍입니다. 좌석을 바꾸거나 두 사람의 순서를 뒤집어도 같은 한 쌍이므로 중복해서 세지 않습니다.

### 서로 다른 몸무게의 비율을 세 가지만 확인하는 이유

가벼운 사람의 몸무게를 `w`, 무거운 사람의 몸무게를 `h`라고 하면, 균형 조건은 `w × 가벼운 사람의 거리 = h × 무거운 사람의 거리`입니다. 가벼운 사람은 더 먼 좌석에 앉아야 하므로 가능한 서로 다른 거리 조합은 아래 세 가지뿐입니다.

| 가벼운 사람 거리 | 무거운 사람 거리 | 필요한 무거운 몸무게 |
| --- | --- | --- |
| 3m | 2m | `w × 3 / 2` |
| 4m | 2m | `w × 2` |
| 4m | 3m | `w × 4 / 3` |

따라서 `(3, 2)`, `(2, 1)`, `(4, 3)`을 순회하며 `heavier = weight * numerator // denominator`를 계산합니다. 몸무게는 정수이므로 `weight * numerator`가 `denominator`로 나누어떨어지지 않으면 해당 비율의 짝꿍은 존재하지 않습니다. 실수 계산 대신 `%`로 나누어떨어지는지 먼저 확인하면 정확한 정수 비교가 가능합니다.

### 두 몸무게의 인원 수를 곱하는 이유

예를 들어 몸무게 100인 사람이 2명, 150인 사람이 3명이라면 100인 사람 각각이 150인 사람 3명과 짝을 이룰 수 있으므로 `2 × 3 = 6`쌍입니다. 이를 `count * counts.get(heavier, 0)`으로 계산합니다. 해당 몸무게가 없다면 `get`의 기본값인 0을 반환해 더해지는 쌍이 없습니다.

### 가벼운 몸무게에서 무거운 몸무게만 찾는 이유

100과 150을 짝으로 세었다면 150을 기준으로 다시 100을 찾으면 **같은 두 사람을 중복 계산**하게 됩니다. 현재 몸무게를 가벼운 쪽으로 고정하고 `3/2`, `2`, `4/3`처럼 1보다 큰 비율만 사용하면 서로 다른 몸무게의 각 쌍을 정확히 한 번 셉니다. 같은 몸무게 쌍은 앞의 조합 계산에서 따로 처리하므로 빠지는 경우도 없습니다.

### 예시 입력의 계산 과정

`weights = [100, 180, 360, 100, 270]`에서 같은 몸무게인 100 두 명이 1쌍입니다. 서로 다른 몸무게의 짝은 `(180, 360)`, `(180, 270)`, `(270, 360)`으로 각각 1쌍입니다. 합계는 **4쌍**이며 문제의 예시 결과와 일치합니다.

### 시간 및 공간 복잡도

- **시간 복잡도**: `O(n + u) = O(n)` (`n`은 전체 사람 수, `u`는 서로 다른 몸무게 수). `Counter` 생성에 `O(n)`, 서로 다른 몸무게마다 고정된 세 비율을 확인하는 데 `O(u)`가 필요합니다. 딕셔너리 조회는 평균 `O(1)`입니다.
- **공간 복잡도**: `O(u)` (몸무게별 인원 수를 저장합니다. 문제에서 몸무게는 100~1,000의 정수이므로 `u ≤ 901`입니다.)
