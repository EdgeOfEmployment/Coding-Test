# 숫자 카드 나누기 문제 풀이 공유

[문제 링크: 프로그래머스 135807 숫자 카드 나누기](https://school.programmers.co.kr/learn/courses/30/lessons/135807)

## 1. 접근법과 단순 풀이의 한계

찾으려는 양의 정수 `a`는 다음 중 하나를 만족해야 합니다.

1. `arrayA`의 모든 수를 나누고 `arrayB`의 어떤 수도 나누지 못한다.
2. `arrayB`의 모든 수를 나누고 `arrayA`의 어떤 수도 나누지 못한다.

가능한 수 중 최댓값을 반환하고, 없다면 0을 반환합니다. 원소는 최대 100,000,000이고 배열 길이는 최대 500,000이므로 모든 수를 직접 후보로 검사할 수 없습니다. 개별 원소끼리 비교하는 것도 배열 전체의 공약수 조건을 해결하지 못합니다.

한 배열의 모든 수를 나누는 가장 큰 수는 **그 배열 전체의 최대공약수**입니다. 따라서 두 배열의 최대공약수를 각각 구한 뒤, 상대 배열의 어떤 원소도 나누지 않는지 확인합니다.

## 2. 해결 코드

```python
from math import gcd


def solution(arrayA, arrayB):
    gcdA = arrayA[0]
    for num in arrayA[1:]:
        gcdA = gcd(gcdA, num)

    gcdB = arrayB[0]
    for num in arrayB[1:]:
        gcdB = gcd(gcdB, num)

    answer = 0

    if all(num % gcdA != 0 for num in arrayB):
        answer = gcdA

    if all(num % gcdB != 0 for num in arrayA):
        answer = max(answer, gcdB)

    return answer
```

## 3. 구현 전략 및 이유

### 배열 전체의 최대공약수

예를 들어 `arrayA = [14, 35, 119]`라면 모든 원소를 나누는 수는 공약수여야 하고, 가장 큰 공약수는 7입니다. Python의 `math.gcd()`를 순서대로 누적해 배열 전체의 최대공약수를 구합니다.

### 최대공약수만 검사해도 되는 이유

`gcdA`가 상대 배열의 어떤 수를 나눈다면, `gcdA`의 더 작은 약수도 그 수를 나눕니다. 따라서 작은 약수를 추가로 검사해도 조건을 만족할 수 없습니다. 반대로 `gcdA`가 상대 배열의 어느 수도 나누지 못한다면 A의 공약수 중 가장 큰 유효한 답입니다.

`all(num % gcdA != 0 for num in arrayB)`는 상대 배열의 모든 원소가 나누어지지 않는지 확인합니다. A와 B를 기준으로 하는 두 경우를 모두 확인하고 더 큰 값을 택합니다. 둘 다 실패하면 초기값 0을 반환합니다.

### 복잡도

배열 길이를 N, 원소의 최댓값을 M이라고 하면 최대공약수 계산에 **O(N log M)**, 상대 배열 검사에 **O(N)**이 걸립니다. 전체 시간 복잡도는 **O(N log M)**이고 추가 공간 복잡도는 **O(1)**입니다.

> 배열 전체를 나누는 가장 큰 수가 필요할 때는 최대공약수를 먼저 구하고, 상대 배열에 대한 조건을 검사합니다.
