# 가장 긴 팰린드롬

## 문제 링크

[프로그래머스 - 가장 긴 팰린드롬](https://school.programmers.co.kr/learn/courses/30/lessons/12904)

## 문제 해결 방법

처음에는 문자열에서 팰린드롬이 되는 부분을 찾아서 가장 긴 문자열의 길이를 구해야 한다고 생각했다. 팰린드롬은 앞에서 읽어도 뒤에서 읽어도 같은 문자열이므로, 문자열의 각 위치를 기준으로 양쪽 문자를 비교하면 찾을 수 있다고 생각했다.

문제를 해결하기 위해 문자열의 각 위치를 중심으로 잡고, 왼쪽과 오른쪽으로 확장하면서 문자가 같은지 확인하는 방법을 사용했다.

예를 들어 문자열이 `"abacde"`라면 `b`를 중심으로 왼쪽의 `a`와 오른쪽의 `a`를 비교할 수 있다.

```text
a b a c d e
  ↑
중심 b
```

양쪽 문자가 같으면 팰린드롬이 될 수 있으므로 길이를 계산하고, 왼쪽과 오른쪽 인덱스를 한 칸씩 이동하면서 더 바깥쪽 문자도 비교한다.

```java
left--;
right++;
```

문자가 같지 않으면 더 이상 확장할 수 없으므로 반복을 종료한다.

## 홀수 길이와 짝수 길이 구분하기

문제를 풀면서 팰린드롬은 홀수 길이와 짝수 길이로 나눠서 확인해야 한다는 것을 알게 되었다.

홀수 길이 팰린드롬은 가운데 문자가 하나 있는 형태이다. 예를 들어 `"aba"`는 가운데 `b`를 기준으로 양쪽 문자를 비교할 수 있다.

```text
a b a
  ↑
중심 문자
```

따라서 왼쪽과 오른쪽 인덱스를 다음과 같이 설정했다.

```java
int hleft = i - 1;
int hright = i + 1;
```

반면 `"abba"`처럼 짝수 길이인 팰린드롬은 가운데 문자가 하나가 아니라 두 문자 사이가 중심이 된다.

```text
a b b a
  ↑ ↑
중심이 되는 두 문자
```

따라서 짝수 길이에서는 다음과 같이 설정했다.

```java
int zleft = i;
int zright = i + 1;
```

이렇게 홀수 길이와 짝수 길이를 모두 검사해서 모든 형태의 팰린드롬을 찾도록 했다.

## 가장 긴 팰린드롬의 길이 구하기

왼쪽과 오른쪽 문자가 같으면 현재 팰린드롬의 길이를 계산했다.

```java
int len = right - left + 1;
```

인덱스의 차이에 `1`을 더하는 이유는 실제 문자 개수를 구하기 위해서이다. 예를 들어 왼쪽 인덱스가 `0`이고 오른쪽 인덱스가 `2`라면, 인덱스의 차이는 `2`이지만 실제 문자는 총 `3`개이다.

현재 팰린드롬의 길이를 구한 다음에는 기존에 저장한 최댓값과 비교했다.

```java
answer = Math.max(answer, len);
```

처음에는 `answer++`를 사용해 문자가 같을 때마다 값을 증가시키려고 했다. 하지만 이렇게 하면 팰린드롬의 전체 길이가 아니라 비교 횟수를 세게 된다는 것을 알게 되었다. 따라서 현재 팰린드롬의 길이를 직접 계산하고, `Math.max()`를 이용해 가장 긴 길이를 저장하도록 수정했다.

또한 팰린드롬이 한 글자뿐인 경우도 있으므로 `answer`의 초기값을 `1`로 설정했다.

## 최종 코드

```java
class Solution {
    public int solution(String s) {
        int answer = 1;
        int n = s.length();

        for (int i = 0; i < n; i++) {
            // 길이가 홀수일 때
            int hleft = i - 1;
            int hright = i + 1;

            while (hleft >= 0 && hright < n) {
                if (s.charAt(hleft) == s.charAt(hright)) {
                    int len = hright - hleft + 1;
                    answer = Math.max(answer, len);

                    hleft--;
                    hright++;
                } else {
                    break;
                }
            }

            // 길이가 짝수일 때
            int zleft = i;
            int zright = i + 1;

            while (zleft >= 0 && zright < n) {
                if (s.charAt(zleft) == s.charAt(zright)) {
                    int len = zright - zleft + 1;
                    answer = Math.max(answer, len);

                    zleft--;
                    zright++;
                } else {
                    break;
                }
            }
        }

        return answer;
    }
}
```

## 어려웠던 점

처음에는 가운데를 기준으로 양쪽 문자를 비교한다는 개념은 이해했지만, `left`와 `right`를 왜 한 칸씩 이동해야 하는지 이해하는 데 어려움이 있었다. 처음 비교한 두 문자가 같더라도 더 바깥쪽 문자까지 비교해야 더 긴 팰린드롬을 찾을 수 있다는 것을 알게 되었다.

또한 홀수 길이와 짝수 길이의 팰린드롬을 구분하는 부분도 어려웠다. 처음에는 가운데 문자 하나를 기준으로 비교하는 방법만 생각했지만, `"abba"`처럼 가운데 두 문자 사이가 중심이 되는 경우도 확인해야 한다는 것을 배웠다.

마지막으로 `answer++`를 이용하는 방법이 아니라, 현재 팰린드롬의 길이를 계산한 후 `Math.max()`로 최댓값을 저장해야 한다는 점을 이해했다.

이번 문제를 통해 문자열의 모든 부분을 직접 비교하는 대신, 각 위치를 중심으로 양쪽으로 확장하면 효율적으로 가장 긴 팰린드롬을 찾을 수 있다는 것을 배웠다.
