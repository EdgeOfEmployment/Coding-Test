# 마법의 엘리베이터

## 문제 해결 방법

마법의 엘리베이터는 `-1`, `+1`, `-10`, `+10`처럼 10의 거듭제곱 단위로 이동할 수 있기 때문에, `storey`의 가장 오른쪽 자리부터 하나씩 처리하는 방식으로 접근했다.

### 1. 가장 오른쪽 숫자 확인

`storey % 10`을 이용하면 현재 숫자의 가장 오른쪽 자리를 가져올 수 있다.

```java
int num = storey % 10;
```

예를 들어 `storey`가 `2554`라면

```text
2554 % 10 = 4
```

이므로 현재 처리할 숫자는 `4`가 된다.

### 2. 현재 숫자가 5보다 작은 경우

현재 숫자가 5보다 작다면 해당 숫자만큼 빼는 것이 가장 적은 횟수이다.

```java
if(num < 5){
    answer += num;
}
```

예를 들어 현재 숫자가 `4`라면 `-1`을 4번 누르는 것이 가장 적다.

```text
4 → 0
```

따라서 4개의 돌을 사용한다.

### 3. 현재 숫자가 5보다 큰 경우

현재 숫자가 5보다 크다면 해당 숫자를 그대로 빼는 것보다 10으로 올리는 것이 더 적은 횟수이다.

```java
else if(num > 5){
    answer += 10 - num;
    storey += 10;
}
```

예를 들어 `6`이라면

```text
6 → 10
```

으로 올리는 데 4번이 필요하다.

또한 `6`을 `10`으로 올리면 앞자리 숫자도 1 증가하기 때문에 `storey += 10`을 해준다.

예를 들어

```text
16 → 20
```

이 되고, 이후 `storey / 10`을 하면

```text
20 / 10 = 2
```

가 되어 다음 자리의 숫자 `2`를 처리할 수 있다.

### 4. 현재 숫자가 5인 경우

현재 숫자가 5라면 내려가는 경우와 올라가는 경우 모두 5번이 필요하기 때문에 앞자리 숫자를 확인해야 한다.

```java
int first = (storey / 10) % 10;
```

`/ 10`을 하면 현재 가장 오른쪽 숫자를 없앨 수 있고, `% 10`을 하면 그다음 숫자를 가져올 수 있다.

예를 들어 `2554`에서

```text
2554 / 10 = 255
255 % 10 = 5
```

이므로 현재 숫자 `4`의 앞자리 숫자는 `5`이다.

5일 때 앞자리 숫자가 5보다 작으면 내려가고, 5 이상이면 올리는 방식으로 처리했다.

```java
if(first < 5){
    answer += num;
}else{
    answer += 10 - num;
    storey += 10;
}
```

### 5. 처리한 자리를 없애고 다음 자리로 이동

현재 자릿수를 처리한 후에는 `storey / 10`을 하여 처리한 가장 오른쪽 숫자를 없앤다.

```java
storey = storey / 10;
```

예를 들어

```text
2554
 ↓
255
 ↓
25
 ↓
2
 ↓
0
```

와 같이 가장 오른쪽 자리부터 차례대로 처리한다.

## 어려웠던 점

처음 구현하려고 했을 때 문제를 어떻게 접근해야 할지 바로 생각나지 않았다. 단순히 `storey`에서 값을 빼는 방식으로 생각했지만, 각 자리의 숫자를 하나씩 처리해야 한다는 점을 파악하는 데 시간이 걸렸다.

특히 `storey % 10`으로 가장 오른쪽 숫자를 가져오고, `storey / 10`으로 해당 자리를 없애면서 다음 자리로 넘어가는 방식을 이해하는 것이 어려웠다.

또한 현재 숫자가 5보다 큰 경우 숫자를 10으로 올리면서 앞자리 숫자까지 1 증가한다는 점도 어려웠다. 예를 들어 `16`에서 6을 올리면 `20`이 되기 때문에 다음에 처리해야 하는 숫자가 1이 아니라 2가 된다.

그리고 숫자가 5인 경우에는 현재 숫자만 보고 결정할 수 없고 앞자리 숫자까지 확인해야 한다는 점도 어려웠다.

처음에는 문제를 보고 어떤 방식으로 풀어야 할지 생각나지 않았지만, **가장 오른쪽 자리부터 확인하고 5를 기준으로 내릴지 올릴지를 결정하는 방식**으로 규칙을 정리하면서 해결할 수 있었다.

이 과정을 통해 문제를 바로 코드로 작성하기보다 **숫자의 각 자리를 어떻게 처리할지 먼저 규칙으로 정리하는 것이 중요하다**는 점을 배웠다.

## 시간 복잡도

`storey`의 각 자릿수를 한 번씩 확인하기 때문에 시간 복잡도는

```text
O(log N)
```

이다.

`storey`의 최대값이 100,000,000이므로 최대 자릿수만큼 반복문을 실행한다.

## 공간 복잡도

추가적인 배열이나 자료구조를 사용하지 않고 변수만 사용하기 때문에 공간 복잡도는

```text
O(1)
```

이다.
