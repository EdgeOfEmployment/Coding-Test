# 점프와 순간 이동

## 문제 해결 방법

처음에는 `0`부터 `N`까지 이동하면서 점프와 순간이동을 하나씩 확인하려고 했다.

하지만 이 문제는 `N`에서 `0`으로 거꾸로 생각하면 쉽게 해결할 수 있다.

현재 위치가 **짝수**라면 순간이동으로 이동한 위치라고 생각할 수 있기 때문에 `2`로 나눈다. 순간이동은 배터리를 사용하지 않는다.

현재 위치가 **홀수**라면 순간이동으로 만들 수 없는 위치이기 때문에 한 칸 점프했다고 생각한다. 점프를 했으므로 `ans`를 1 증가시키고 `n`에서 1을 뺀다.

이 과정을 `n`이 0이 될 때까지 반복한다.

```java
while(n > 0){
    if(n % 2 == 0){
        // 짝수면 순간이동
        n = n / 2;
    }else{
        // 홀수면 점프
        n = n - 1;
        ans++;
    }
}
```

마지막으로 `ans`를 반환하면 최소 배터리 사용량을 구할 수 있다.

## 어려웠던 점

처음에는 `N`까지의 거리를 리스트로 만들어서 리스트에서 하나씩 꺼내면서 풀어야 하나 생각했다.

하지만 `N`이 최대 10억까지 될 수 있기 때문에 모든 거리를 리스트에 저장하는 방법은 비효율적이었다.

그래서 힌트를 이용해 `N`에서 0까지 거꾸로 생각해보았고, **짝수면 2로 나누고 홀수면 1을 빼는 방식**으로 문제를 해결할 수 있다는 것을 알게 되었다.
