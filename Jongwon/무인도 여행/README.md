# 무인도 여행

## 문제 링크

[프로그래머스 - 무인도 여행](https://school.programmers.co.kr/learn/courses/30/lessons/154540)

---

## 문제 해결 과정

처음에는 지도에서 숫자가 있는 칸을 하나씩 확인하면서 어떻게 연결된 숫자들을 하나의 무인도로 묶어서 계산해야 하는지 생각했다.

이 문제에서는 상하좌우로 연결되어 있는 숫자 칸들이 하나의 무인도가 되기 때문에, **연결된 칸을 전부 탐색할 수 있는 DFS를 사용**하기로 했다.

각 무인도의 식량을 계산하기 위해 DFS를 돌면서 현재 위치의 식량을 `sum`에 더하고, 상하좌우에 연결된 칸이 있다면 재귀적으로 DFS를 호출해서 식량을 계속 더했다.

---

## 1. 지도 크기와 방문 배열 만들기

먼저 지도에서 행과 열의 크기를 저장했다.

```java
n = maps.length;
m = maps[0].length();
```

그리고 같은 위치를 여러 번 방문하지 않도록 `visited` 배열을 만들었다.

```java
visited = new boolean[n][m];
```

`visited`는 지도와 같은 크기로 만들어서 각 칸을 방문했는지 확인할 수 있도록 했다.

---

## 2. 상하좌우 이동을 위한 좌표 저장

무인도는 상하좌우로 연결되어 있기 때문에 이동할 방향을 배열로 저장했다.

```java
int[][] dxy = {
    {-1,0},
    {0,1},
    {1,0},
    {0,-1}
};
```

각각

```text
위
오른쪽
아래
왼쪽
```

을 의미한다.

현재 위치가 `(r, c)`라면 다음 위치는 다음과 같이 계산한다.

```java
int nr = r + dxy[i][0];
int nc = c + dxy[i][1];
```

---

## 3. 지도 전체를 확인

이중 반복문을 이용해서 지도의 모든 칸을 확인한다.

```java
for(int i=0; i<n; i++){
    for(int j=0; j<m; j++){
```

현재 칸이

* 아직 방문하지 않았고
* `X`가 아니라면

새로운 무인도를 발견한 것이므로 DFS를 시작한다.

```java
if(!visited[i][j] && maps[i].charAt(j) != 'X'){
    list.add(dfs(maps, i, j));
}
```

DFS가 끝나면 해당 무인도의 식량 총합을 반환하기 때문에 그 값을 `list`에 저장한다.

---

## 4. DFS에서 현재 위치 방문 처리

DFS가 시작되면 현재 위치를 방문했다고 표시한다.

```java
visited[r][c] = true;
```

이렇게 하면 이미 방문했던 칸을 다시 방문하지 않게 된다.

---

## 5. 현재 칸의 식량을 sum에 저장

현재 위치에 있는 식량을 `sum`에 저장한다.

```java
int sum = maps[r].charAt(c) - '0';
```

`maps`에는 숫자가 문자 형태로 저장되어 있기 때문에 `- '0'`을 이용해서 숫자로 변환했다.

예를 들어:

```text
'5' → 5
'9' → 9
```

가 된다.

`sum`은 **현재 무인도에서 찾은 식량의 총합을 저장하는 변수**이다.

---

## 6. 상하좌우 탐색

현재 위치에서 상하좌우를 확인한다.

먼저 다음 위치가 지도 범위 안에 있는지 확인한다.

```java
if(nr >= 0 && nr < n && nc >= 0 && nc < m){
```

범위 안에 있다면 해당 위치가 아직 방문하지 않았고 `X`가 아닌지도 확인한다.

```java
if(!visited[nr][nc] && maps[nr].charAt(nc) != 'X'){
    sum += dfs(maps, nr, nc);
}
```

조건을 만족하면 DFS를 다시 실행해서 연결된 무인도를 계속 탐색한다.

---

## 7. 식량을 sum에 계속 더하기

이 문제에서 가장 중요한 부분은 다음 코드이다.

```java
sum += dfs(maps, nr, nc);
```

현재 칸의 식량을 `sum`에 저장한 상태에서 연결된 다음 칸으로 이동한다.

예를 들어 무인도가 다음과 같이 연결되어 있다면,

```text
5 - 9 - 1
```

처음에는:

```text
sum = 5
```

다음 `9`를 탐색하면:

```text
sum = 5 + 9
```

마지막 `1`까지 탐색하면:

```text
sum = 5 + 9 + 1
    = 15
```

이렇게 하나의 무인도에 있는 모든 식량을 더할 수 있다.

DFS가 끝나면:

```java
return sum;
```

을 통해 해당 무인도의 식량 총합을 반환한다.

---

## 8. 각 무인도의 식량을 list에 저장

DFS에서 반환된 식량 총합을 `list`에 저장한다.

```java
list.add(dfs(maps, i, j));
```

예를 들어 무인도가 3개이고 각각의 식량 합계가

```text
15
3
7
```

이라면:

```text
list = [15, 3, 7]
```

이 된다.

---

## 9. 무인도가 없는 경우

모든 지도를 확인했는데 `list`가 비어 있다면 무인도가 하나도 없는 것이다.

```java
if(list.isEmpty()){
    return new int[]{-1};
}
```

문제에서 무인도가 없다면 `[-1]`을 반환하라고 했기 때문에 해당 값을 반환한다.

---

## 10. 오름차순 정렬

모든 무인도의 식량을 구한 후 오름차순으로 정렬한다.

```java
Collections.sort(list);
```

예를 들어:

```text
[15, 3, 7]
```

이었다면:

```text
[3, 7, 15]
```

로 정렬된다.

---

## 11. ArrayList를 int[]로 변환

문제에서 최종적으로 반환해야 하는 자료형은 `int[]`이기 때문에 `ArrayList<Integer>`에 저장한 값을 배열로 옮긴다.

```java
answer = new int[list.size()];

for(int i=0; i<list.size(); i++){
    answer[i] = list.get(i);
}
```

마지막으로:

```java
return answer;
```

을 통해 정답을 반환한다.

---

## 풀이 핵심 정리

이 문제에서 사용한 자료구조와 변수의 역할은 다음과 같다.

| 자료구조 / 변수 | 역할                 |
| --------- | ------------------ |
| `maps`    | 무인도의 위치와 식량을 저장    |
| `visited` | 방문한 칸을 체크          |
| `dxy`     | 상하좌우 이동 방향 저장      |
| `sum`     | 하나의 무인도에 있는 식량의 총합 |
| `list`    | 각 무인도의 식량 총합 저장    |
| `answer`  | 최종 결과를 저장          |

전체적인 흐름은 다음과 같다.

```text
① 지도 전체를 한 칸씩 확인
        ↓
② 방문하지 않았고 X가 아닌 칸 발견
        ↓
③ 해당 위치에서 DFS 시작
        ↓
④ 현재 칸을 방문 처리
        ↓
⑤ 현재 칸의 식량을 sum에 저장
        ↓
⑥ 상하좌우를 확인
        ↓
⑦ 연결된 숫자 칸이면 DFS 재귀 호출
        ↓
⑧ 연결된 모든 칸의 식량을 sum에 더함
        ↓
⑨ sum을 반환
        ↓
⑩ 해당 무인도의 식량을 list에 저장
        ↓
⑪ 모든 무인도 탐색
        ↓
⑫ list를 오름차순 정렬
        ↓
⑬ int[]로 변환하여 반환
```

---

어려웠던 점

오랜만에 DFS를 활용해서 문제를 풀다 보니 DFS의 재귀 구조와 방문 처리 방식이 처음에는 헷갈렸다. 특히 현재 위치에서 상하좌우를 탐색하고, 연결된 칸의 식량을 sum에 더한 뒤 return하는 과정을 이해하는 데 시간이 걸렸다.

또한 각 무인도의 식량을 ArrayList<Integer>에 저장한 후, 문제에서 요구하는 int[] 배열로 변환하는 과정도 어려웠다. list.get(i)를 이용해 리스트의 값을 하나씩 배열에 옮기는 방법을 익힐 수 있었다.
