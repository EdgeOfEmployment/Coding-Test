# 가장 큰 정사각형 찾기

## 문제 링크

[프로그래머스 - 가장 큰 정사각형 찾기](https://school.programmers.co.kr/learn/courses/30/lessons/12905)

## 문제 해결 방법

처음에는 `1`이 있는 칸을 찾은 다음, 주변에 `1`이 있는지 확인하면서 가장 큰 정사각형을 찾아야 하는 문제라고 생각했다. 그래서 처음에는 BFS를 이용해서 `1`이 있는 위치를 탐색하는 문제인가 생각했다.

하지만 행과 열의 크기가 최대 1,000이기 때문에 모든 `1`을 기준으로 주변을 탐색하는 방법은 비효율적이었다.

문제를 다시 생각해보니 현재 칸을 기준으로 **왼쪽, 위, 왼쪽 위의 값을 이용하면 현재 칸에서 만들 수 있는 정사각형의 크기를 알 수 있다는 것**을 알게 되었다.

현재 칸을 정사각형의 오른쪽 아래라고 생각하면, 왼쪽 위, 위, 왼쪽 세 칸을 확인할 수 있다.

예를 들어 세 값이 모두 `1`이라면 현재 칸까지 포함해서 `2 × 2` 정사각형을 만들 수 있다.

```text
1 1
1 ?
```

따라서 현재 칸의 값을 `2`로 바꿔서 저장한다.

여기서 `2`는 원래 입력값이 `2`라는 의미가 아니라, **현재 칸을 오른쪽 아래로 했을 때 만들 수 있는 정사각형의 한 변의 길이가 2라는 의미**이다.

더 큰 정사각형을 만들 수 있는 경우에는 `3`, `4`처럼 저장한다.

현재 칸의 정사각형 크기를 구할 때는 왼쪽 위, 위, 왼쪽 중 가장 작은 값을 사용한다.

```java
int min = Math.min(Math.min(leftup, up), left);
```

가장 작은 값을 사용하는 이유는 세 방향 중 하나라도 작은 정사각형밖에 만들지 못한다면 현재 칸에서도 그보다 큰 정사각형을 만들 수 없기 때문이다.

그래서 현재 칸에서는

```java
board[i][j] = min + 1;
```

을 사용한다.

`+1`은 현재 칸을 하나 추가한다는 의미이다.

계산하면서 가장 큰 한 변의 길이를 `answer`에 저장하고, 문제에서 요구하는 것은 넓이이므로 마지막에 `answer * answer`를 반환한다.

## 처음 제출했을 때 발생한 문제

처음에는 다음과 같이 작성했다.

```java
int answer = 0;

if(i > 0 && j > 0 && board[i][j] == 1){
    ...
    answer = Math.max(answer, board[i][j]);
}
```

이 코드는 대부분의 테스트를 통과했지만 정확성 테스트에서 하나가 실패했다.

처음에는 정사각형의 크기를 계산하는 부분만 확인했는데, `i > 0 && j > 0` 조건 때문에 **첫 번째 행과 첫 번째 열에 있는 `1`은 `answer`에 반영되지 않는 문제**가 있었다.

그래서 `board[i][j] == 1`인지 먼저 확인하고, 첫 번째 행이나 첫 번째 열이 아니라면 정사각형의 크기를 계산하도록 수정했다.

수정한 코드는 다음과 같다.

```java
class Solution
{
    public int solution(int [][]board){
        int answer = 0;
        int n = board.length;
        int m = board[0].length;
        
        for(int i=0; i<n; i++){
            for(int j=0; j<m; j++){
                if(board[i][j] == 1){
                    
                    if(i>0 && j>0){
                        // 오른쪽 아래 칸을 기준으로 위, 왼쪽, 왼쪽 위 확인
                        int leftup = board[i-1][j-1];
                        int up = board[i-1][j];
                        int left = board[i][j-1];
                        
                        int min = Math.min(Math.min(leftup, up), left);
                        
                        board[i][j] = min + 1;
                    }
                    
                    answer = Math.max(answer, board[i][j]);
                }
            }
        }
            
        return answer * answer;
    }
}
```

처음에는 BFS를 이용하는 문제라고 생각했지만, 현재 칸에서 이미 계산된 왼쪽, 위, 왼쪽 위의 값을 다시 활용한다는 점에서 DP 문제라는 것을 알게 되었다.

특히 `1`이 `2`, `3`으로 바뀌는 것이 단순히 값을 변경하는 것이 아니라 **해당 칸을 오른쪽 아래로 했을 때 만들 수 있는 정사각형의 크기를 저장하는 것**이라는 점을 이해하는 것이 어려웠다.
