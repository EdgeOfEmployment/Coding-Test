# 귤 고르기

## 문제 해결 방법

귤을 크기별로 분류했을 때 서로 다른 종류의 수를 최소화해야 하므로, 먼저 각 크기의 귤이 몇 개씩 존재하는지 확인했다.

### 1. HashMap을 이용해 귤의 개수 세기

`HashMap`의 key에는 귤의 크기를 저장하고, value에는 해당 크기의 귤 개수를 저장했다.

```java
map.put(tangerine[i], map.getOrDefault(tangerine[i], 0) + 1);
```

`getOrDefault()`를 사용하여 해당 크기가 처음 등장하면 0에서 1을 더하고, 이미 존재한다면 기존 개수에 1을 더했다.

예를 들어

```text
[1, 3, 2, 5, 4, 5, 2, 3]
```

을 입력하면 크기별 개수는 다음과 같다.

```text
1 → 1개
2 → 2개
3 → 2개
4 → 1개
5 → 2개
```

### 2. 귤의 개수만 List에 저장

서로 다른 크기 자체는 중요하지 않고, 각 크기의 귤이 몇 개 있는지가 중요하기 때문에 `map.values()`를 이용하여 개수만 `List`에 저장했다.

```java
List<Integer> list = new ArrayList<>(map.values());
```

### 3. 많은 귤이 있는 종류부터 선택

서로 다른 종류의 수를 최소화하려면 한 종류에서 최대한 많은 귤을 선택하는 것이 유리하다.

따라서 귤의 개수를 내림차순으로 정렬했다.

```java
Collections.sort(list, Collections.reverseOrder());
```

예를 들어

```text
[1, 2, 2, 1, 2]
```

가

```text
[2, 2, 2, 1, 1]
```

로 정렬된다.

### 4. k개를 채울 때까지 종류 선택

정렬된 리스트를 처음부터 탐색하면서 현재 종류의 귤을 선택했다.

현재 종류의 귤 개수보다 필요한 귤의 개수 `k`가 더 많다면 해당 종류의 귤을 모두 사용하고 `k`에서 그 개수를 뺐다.

```java
k -= list.get(i);
answer++;
```

반대로 현재 종류의 귤 개수만으로 필요한 귤을 모두 채울 수 있다면 해당 종류를 하나 추가하고 반복을 종료했다.

```java
if(k <= list.get(i)){
    answer++;
    break;
}
```

이렇게 하면 가장 많은 귤을 가진 종류부터 사용하면서 필요한 `k`개의 귤을 최소한의 종류로 선택할 수 있다.

## 어려웠던 점

가장 어려웠던 부분은 마지막에 `for`문을 돌면서 `k`와 현재 귤의 개수를 어떻게 비교해야 하는지 이해하는 것이었다.

처음에는 단순히 귤의 개수를 `k`에서 빼고 `k`가 0보다 작아지면 종료하려고 했다. 하지만 한 종류의 귤을 반드시 모두 선택해야 하는 것이 아니라, 마지막 종류에서는 필요한 개수만큼만 선택할 수 있다는 점을 이해하는 것이 어려웠다.

예를 들어 `k`가 2이고 현재 종류의 귤이 3개라면 3개를 모두 선택하는 것이 아니라 해당 종류에서 2개만 선택하면 된다.

따라서 다음과 같이 `k`와 현재 종류의 귤 개수를 먼저 비교해야 한다는 것을 알게 되었다.

또한 귤을 map에 넣은 후 value를 왜 리스트로 뽑아서 하는지 이해가 안가서 ai를 활용해 힌트를 얻었다.

```java
if(k <= list.get(i)){
    answer++;
    break;
}
```

이 과정을 통해 단순히 반복문을 작성하는 것보다 **현재 필요한 개수와 가지고 있는 개수를 비교하면서 종료 조건을 설계하는 것이 중요하다**는 점을 배웠다.

## 시간 복잡도

귤의 개수를 세는 과정은 `O(N)`이고, 종류별 개수를 정렬하는 과정은 최대 `O(N log N)`이다.

따라서 전체 시간 복잡도는

```text
O(N log N)
```

이다.

## 공간 복잡도

귤의 종류별 개수를 저장하기 위해 `HashMap`과 `List`를 사용하므로 공간 복잡도는

```text
O(N)
```

이다.
