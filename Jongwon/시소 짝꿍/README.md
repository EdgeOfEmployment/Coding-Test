# 시소 짝꿍

## 문제 링크

[프로그래머스 - 시소 짝꿍](https://school.programmers.co.kr/learn/courses/30/lessons/152996)

## 문제 해결 방법

처음에는 몸무게가 서로 다른 사람들을 하나씩 비교하면서 시소가 균형을 이루는지 확인해야 하나 생각했다. 하지만 `weights`의 길이가 최대 100,000이기 때문에 모든 사람을 서로 비교하면 시간이 오래 걸릴 것 같았다.

문제를 다시 보니 시소가 균형을 이루려면 `몸무게 × 거리`가 같아야 한다는 것을 이용할 수 있었다.

시소의 거리는 `2m`, `3m`, `4m`이므로 같은 몸무게를 제외하면 가능한 몸무게의 비율은 다음과 같다.

```text
2 : 3
2 : 4
3 : 4
```

예를 들어 `180`과 `360`은

```text
180 × 4 = 360 × 2
720 = 720
```

이므로 시소 짝꿍이 된다.

그래서 `HashMap`에 지금까지 확인한 사람들의 몸무게와 그 몸무게를 가진 사람의 수를 저장했다.

```text
몸무게 → 사람 수
```

현재 몸무게 `w`를 기준으로 같은 몸무게인지 확인하고, `2 : 3`, `2 : 4`, `3 : 4` 비율에 해당하는 몸무게가 `map`에 있는지도 확인했다.

이때 입력 순서에 따라서 현재 몸무게가 더 무거울 수도 있고 더 가벼울 수도 있기 때문에 각 비율을 양쪽 방향으로 확인했다.

예를 들어 현재 몸무게가 `270`이고 앞에 `360`이 있었다면

```text
270 × 4 / 3 = 360
```

을 계산해서 `360`인 사람이 `map`에 있는지 확인한다.

짝꿍을 확인한 후에는 현재 몸무게를 `map`에 저장한다. 이렇게 하면 현재 사람을 자기 자신과 짝꿍으로 계산하지 않고, 앞에서 나온 사람들과만 비교할 수 있다.

또한 같은 몸무게를 가진 사람이 여러 명 있을 수 있기 때문에 단순히 존재 여부만 확인하는 것이 아니라 `map.get()`으로 해당 몸무게를 가진 사람의 수를 가져와서 `answer`에 더했다.

## 어려웠던 점

처음에는 `HashMap`을 사용해서 몸무게가 같은 사람들을 찾는 것까지는 생각했지만, 서로 다른 몸무게가 어떤 경우에 시소의 균형을 이루는지 정리하는 것이 어려웠다.

처음에는 `2 : 3`, `2 : 4`, `3 : 4` 중 한 방향만 확인하면 된다고 생각했다. 하지만 입력 순서에 따라서 짝꿍이 되는 사람이 아직 `map`에 없을 수 있다는 문제가 있었다.

예를 들어 `360`이 먼저 나오고 `270`이 나중에 나오면 `360`을 확인할 때는 `270`이 아직 `map`에 없기 때문에 짝꿍을 찾을 수 없었다.

그래서 `2 : 3`과 `3 : 2`, `2 : 4`와 `4 : 2`, `3 : 4`와 `4 : 3`처럼 양쪽 방향을 모두 확인해야 한다는 것을 알게 되었다.

또한 `2 : 4`와 `1 : 2`가 같은 비율이라는 것도 알게 되었다. 이번에는 문제에서 주어진 시소의 거리인 `2m`, `3m`, `4m`을 그대로 이해하기 위해 코드에서도 `2 : 4`로 작성했다.

마지막으로 `map.containsKey()`는 해당 몸무게를 가진 사람이 있는지 확인하고, `map.get()`은 그 몸무게를 가진 사람이 몇 명인지 가져온다는 차이를 이해하는 것이 어려웠다. 같은 몸무게의 사람이 여러 명 있을 수 있기 때문에 `containsKey()`로 존재 여부를 확인한 후 `get()`으로 사람 수를 더해야 했다.

## 코드

```java
import java.util.*;

class Solution {
    public long solution(int[] weights) {
        long answer = 0;

        Map<Integer, Integer> map = new HashMap<>();

        for(int i = 0; i < weights.length; i++){
            int w = weights[i];

            // 같은 몸무게
            if(map.containsKey(w)){
                answer += map.get(w);
            }

            // 2 : 3
            if(w * 2 % 3 == 0){
                int a = w * 2 / 3;

                if(map.containsKey(a)){
                    answer += map.get(a);
                }
            }

            // 3 : 2
            if(w * 3 % 2 == 0){
                int b = w * 3 / 2;

                if(map.containsKey(b)){
                    answer += map.get(b);
                }
            }

            // 2 : 4
            if(w * 2 % 4 == 0){
                int c = w * 2 / 4;

                if(map.containsKey(c)){
                    answer += map.get(c);
                }
            }

            // 4 : 2
            int d = w * 4 / 2;

            if(map.containsKey(d)){
                answer += map.get(d);
            }

            // 3 : 4
            if(w * 3 % 4 == 0){
                int e = w * 3 / 4;

                if(map.containsKey(e)){
                    answer += map.get(e);
                }
            }

            // 4 : 3
            if(w * 4 % 3 == 0){
                int f = w * 4 / 3;

                if(map.containsKey(f)){
                    answer += map.get(f);
                }
            }

            // 현재 몸무게 저장
            map.put(w, map.getOrDefault(w, 0) + 1);
        }

        return answer;
    }
}
```
