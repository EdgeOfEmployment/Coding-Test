# 다리를 지나는 트럭 - 코드 풀이

## 문제 해결 방법

트럭은 정해진 순서대로 다리를 건너며, 다리에는 최대 `bridge_length`개의 트럭이 올라갈 수 있고 최대 `weight` 이하의 무게를 견딜 수 있다.

처음에는 트럭을 큐에 저장하고 무게가 초과되면 앞의 트럭을 제거하는 방식으로 접근하였다.

하지만 단순히 트럭의 무게만 저장하면 트럭이 언제 다리를 빠져나가는지 알 수 없다는 문제가 있었다.

따라서 큐를 단순한 트럭 저장 공간이 아닌 **다리의 상태를 표현하는 공간**으로 사용하였다.

큐에는 다음 값을 저장한다.

- 트럭 무게 : 현재 다리 위에 있는 트럭
- `0` : 트럭이 없는 빈 공간

즉, 큐의 크기를 다리 길이와 동일하게 유지하면서 트럭이 이동하는 과정을 시뮬레이션하였다.


---

## 1. 트럭을 순서대로 처리

```java
for(int i = 0; i < truck_weights.length; i++)
```

모든 트럭을 입력 순서대로 확인한다.

현재 트럭이 다리에 올라갈 수 있는지 확인하고, 올라갈 수 없다면 올라갈 수 있을 때까지 시간을 증가시키며 반복한다.


---

## 2. 시간 증가

```java
time++;
```

while문이 한 번 실행될 때마다 1초가 흐른다고 생각한다.

트럭이 바로 올라가지 못하는 경우에는 큐에 `0`을 추가하여 빈 공간을 차지하게 한다.

예를 들어 다리 위 상태가

```
[7]
```

인 상황에서 다음 트럭이 무게 제한 때문에 올라가지 못하면

```
[7,0]
```

으로 표현한다.

여기서 `0`은 트럭이 없는 다리의 한 칸을 의미한다.


---

## 3. 다리가 꽉 찬 경우 트럭 제거

```java
if(q.size() == bridge_length){
    sum -= q.poll();
}
```

큐의 크기가 다리 길이와 같다면 다리가 꽉 찬 상태이다.

이때 큐의 가장 앞에 있는 값을 제거한다.

큐의 앞쪽은 다리의 출구이므로 먼저 들어온 트럭이 먼저 빠져나간다.


예시

```
q = [7,4]
```

이면

```
7 제거

q = [4]
```

가 된다.

제거된 트럭의 무게만큼 현재 다리 위의 총 무게도 감소시킨다.


---

## 4. 새로운 트럭이 올라갈 수 있는지 확인

```java
if(sum + truck_weights[i] <= weight)
```

현재 다리 위의 트럭 무게와 새로운 트럭의 무게를 더했을 때 제한 무게 이하인지 확인한다.

조건을 만족하면 트럭을 다리에 올린다.

```java
q.offer(truck_weights[i]);
sum += truck_weights[i];
```

큐 뒤쪽에 새로운 트럭을 추가하고 현재 무게를 증가시킨다.

트럭이 정상적으로 올라갔으므로 다음 트럭을 확인한다.


---

## 5. 무게 제한 때문에 올라가지 못하는 경우

```java
q.offer(0);
```

현재 트럭이 올라갈 수 없다면 큐에 `0`을 추가한다.

`0`은 트럭이 없는 빈 공간을 의미한다.

이를 통해 시간이 흐르면서 앞쪽 트럭이 다리를 빠져나가는 과정을 표현한다.


---

## 6. 마지막 트럭이 빠져나가는 시간 추가

모든 트럭이 다리에 올라간 후에도 마지막 트럭은 아직 다리를 건너는 중이다.

따라서 마지막 트럭이 다리를 완전히 빠져나가는 시간을 추가한다.

```java
time += bridge_length;
```


---

## 사용한 자료구조

### Queue<Integer>

다리 위의 상태를 저장하기 위해 Queue를 사용하였다.

큐의 역할:

- 큐 앞 : 다리를 빠져나가는 위치
- 큐 뒤 : 새로운 트럭이 들어오는 위치
- 숫자 : 트럭의 무게
- `0` : 빈 공간

추가적으로 현재 다리 위의 총 무게를 관리하기 위해 `sum` 변수를 사용하였다.


---

## 배운 점

처음에는 큐에 트럭의 무게만 저장하고 무게 제한을 초과하면 앞의 트럭을 제거하는 방식으로 접근하였다.

하지만 이 방식은 트럭이 언제 다리를 빠져나가는지 알 수 없다는 문제가 있었다.

이를 해결하기 위해 큐를 단순한 저장 공간이 아닌 **다리 자체를 표현하는 공간**으로 활용하였다.

특히 `0`을 빈 공간으로 활용하여 트럭의 이동 시간을 표현하는 방법을 통해 큐를 이용한 시뮬레이션 문제의 접근 방식을 이해할 수 있었다.
