# 2 x n 타일링

## 문제 링크

[프로그래머스 - 2 x n 타일링](https://school.programmers.co.kr/learn/courses/30/lessons/12900)

## 문제 해결 방법

처음에는 `n`이 주어졌을 때 타일을 하나씩 배치하면서 가능한 경우를 모두 찾아야 하나 생각했다. 하지만 `n`이 최대 60,000이기 때문에 모든 경우를 직접 확인하는 방법은 경우의 수가 너무 많아질 것 같았다.

문제를 작은 경우부터 생각해보니 규칙을 찾을 수 있었다.

```text
n = 1 → 1가지
n = 2 → 2가지
n = 3 → 3가지
n = 4 → 5가지
n = 5 → 8가지
```

`n = 3`부터는 앞의 두 경우의 수를 더하면 현재 경우의 수가 만들어졌다.

```text
n = 3 → 2 + 1 = 3
n = 4 → 3 + 2 = 5
n = 5 → 5 + 3 = 8
```

그래서 `n`번째 타일을 채우는 방법의 수는

```text
a[n] = a[n-1] + a[n-2]
```

라는 규칙을 이용할 수 있다고 생각했다.

이를 배열에 저장하기 위해 `a` 배열을 만들고, 문제에서 구한 기본값인 `a[1] = 1`, `a[2] = 2`를 먼저 저장했다.

그다음 `3`부터 `n`까지 반복하면서 이전 두 값을 더해 현재 값을 구했다.

```java
a[i] = (a[i-1] + a[i-2]) % 1000000007;
```

경우의 수가 매우 커질 수 있기 때문에 문제에서 요구한 `1,000,000,007`로 나눈 나머지를 저장했다.

마지막에는 `n`까지 계산한 `a[n]`을 반환했다.


## 코드

```java
import java.util.*;

/*
가로 2, 세로 1인 직사각경
가로 n, 세로 2인 바닥을 채워야함
직사각형을 채울 수 있는 방법의 수를 return
n이 1이면 세로 직사 1개
n이 2이면 가로 직사 2개 또는 세로 직사 2개
n이 3이면 가로 직사 2랑 세로 직사 1개 * 2 / 세로 직사 3개
n이 4면 5개
n이 5면 8개
*/

class Solution {
    public int solution(int n) {
        int answer = 0;
        int[] a = new int[n + 1];

        a[1] = 1;
        a[2] = 2;

        // n = n-1 + n-2가 계속 반복 됨
        for(int i = 3; i <= n; i++){
            a[i] = (a[i-1] + a[i-2]) % 1000000007;
        }

        return a[n];
    }
}
```
