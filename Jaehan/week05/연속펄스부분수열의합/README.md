# 연속 펄스 부분 수열의 합 문제 풀이 공유

[문제 링크](https://school.programmers.co.kr/learn/courses/30/lessons/161988)

## 1. 접근법과 단순 풀이의 한계 (처음 시도한 슬라이싱 접근)

수열의 길이 $n$이 최대 500,000까지 주어지기 때문에, 모든 스텝(길이)별로 배열을 잘라서(슬라이싱) 모든 연속 부분 수열의 합을 구하는 접근은 시간 초과를 유발할 수밖에 없었습니다.

- **국소적/전체 탐색의 함정**: 1부터 $n$까지의 길이에 대해 모든 시작 위치에서 슬라이싱을 수행하면 전체 시간 복잡도가 $O(N^2)$ 또는 그 이상이 되어, 50만 개에 달하는 원소 개수를 감당하지 못하고 프로그래머스 시간 제한을 초과하게 됩니다.
- **방향 수정**: 슬라이싱 대신 **펄스 수열을 미리 곱해둔 두 개의 배열을 만들고, 단 한 번의 순회로 최댓값을 찾는 카데인 알고리즘(Kadane's Algorithm)** 방식으로 접근을 완전히 전환했습니다.

## 2. 해결 코드

```python
def solution(sequence):
  # 1로 시작하는 펄스 수열을 곱한 배열 ([1, -1, 1, ...])
  seq1 = [s * (1 if i % 2 == 0 else -1) for i, s in enumerate(sequence)]

  # -1로 시작하는 펄스 수열을 곱한 배열 ([-1, 1, -1, ...])
  seq2 = [s * (-1 if i % 2 == 0 else 1) for i, s in enumerate(sequence)]

  # 카데인 알고리즘 정의
  def kadane(arr):
    max_sum = arr[0]  # 0번 인덱스를 초기 최댓값으로 설정
    current_sum = arr[0]  # 0번 인덱스를 초기 부분 수열 합으로 설정

    # 1번 인덱스부터 끝까지 순회 (0번은 이미 포함됨)
    for x in arr[1:]:
      current_sum = max(x, current_sum + x)
      max_sum = max(max_sum, current_sum)

    return max_sum

  # 두 배열 중 더 큰 연속 부분 수열의 합을 반환
  return max(kadane(seq1), kadane(seq2))

```

## 3. 구현 전략 및 이유

### 펄스 수열 변환을 통한 문제 단순화

문제에서 요구하는 펄스 수열은 `[1, -1, 1, -1, ...]` 또는 `[-1, 1, -1, 1, ...]` 두 가지 형태 중 하나로 시작합니다.

- 원래 수열에 이 두 가지 패턴을 미리 곱해두면, 문제는 단순히 "새로 만든 두 배열 각각에서 '가장 큰 연속 부분 수열의 합'을 구하는 문제"로 바뀝니다.
- 이를 통해 복잡한 구간 비교 연산을 제거할 수 있습니다.

### 카데인 알고리즘(Kadane's Algorithm)을 활용한 $O(N)$ 최적화

슬라이싱을 일일이 하지 않고 배열을 단 한 번만 순회하면서 최적의 연속 부분 수열 합을 찾는 핵심 로직입니다.

1. **초기값 설정**

- 첫 번째 원소인 `arr[0]`을 현재 부분 수열 합(`current_sum`)과 전체 최댓값(`max_sum`)의 초기값으로 두고 시작합니다. 이는 0번 인덱스 값도 결과에 자연스럽게 포함됨을 의미합니다.

2. **매 순간의 결단 (`current_sum = max(x, current_sum + x)`)**

- 1번 인덱스부터 끝까지 순회하면서 판단합니다.
- *"지금까지 누적해온 합(`current_sum`)에 현재 값(`x`)을 이어 붙이는 것이 이득인가, 아니면 이전 누적 합은 다 버리고 `x`부터 새로 시작하는 것이 이득인가?"*를 매번 비교합니다.

3. **최댓값 갱신 (`max_sum = max(max_sum, current_sum)`)**

- 매 단계마다 갱신되는 `current_sum`과 지금까지의 `max_sum`을 비교하여 가장 큰 값을 유지합니다.

- **시간 복잡도**: $O(N)$ (두 개의 배열 `seq1`, `seq2`를 각각 정확히 한 번씩만 순회하므로 수열의 길이 $N$에 비례합니다.)
- **공간 복잡도**: $O(N)$ (펄스 수열이 곱해진 두 개의 새로운 배열을 생성하는 공간을 사용합니다.)
